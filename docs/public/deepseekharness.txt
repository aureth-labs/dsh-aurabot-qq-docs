## 3. 阶段 A：环境体检（只读）

依次执行并汇报：

- 版本：`node -v`、`npm -v`
- 路径：Windows `where node`；mac/Linux `which -a node`
- 系统：Windows `ver` / `$PSVersionTable.PSVersion`；mac `sw_vers`；Linux `uname -a`
- 端口：Windows `netstat -ano | findstr :8787`；mac/Linux `lsof -nP -iTCP:8787 -sTCP:LISTEN`
- 磁盘：安装盘至少 2 GB 空闲
- 目录：目标文件夹是否存在、是否为空

判定：

- Node 缺失或 < 24.9.0 → 进入阶段 B
- Node 合格 → 跳过阶段 B
- 端口被占 → 换 8788 或 8790；若是旧 dsh，先按阶段 E 的停止逻辑处理
- 有多个 node → 先解决 PATH 优先级，不要在旧版本上硬装

**常见坑**：PowerShell 里 `npm` 报“npm.ps1 无法加载”，改用 `npm.cmd`；PowerShell 5.1 不支持 `&&`，命令要分行或用 `;`。

## 4. 阶段 B：安装 / 升级 Node.js（需我同意）

原则：官方安装包或系统包管理器；装完**新开终端**再验证；不要用第三方“一键脚本”。

### Windows

优先 winget：

```
winget install --id OpenJS.NodeJS.LTS -e --accept-source-agreements --accept-package-agreements
```

装完关闭当前终端重新打开，执行 `node -v`。

备选：从 `https://nodejs.org/en/download` 下载 LTS x64 的 .msi，双击安装（勾选 Add to PATH）。
已有 nvm-windows / fnm：`nvm install 24` 或 `fnm install 24`，再 `nvm use 24` / `fnm use 24`。

### macOS

```
brew install node@24
```

没有 Homebrew 就用官网 .pkg。验证 `node -v`。

### Linux

优先 nvm（装到用户目录，不动系统包）：

```
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
```

新开终端后 `nvm install 24 && nvm use 24`。或用 NodeSource 的 24.x 仓库；不要用发行版自带的老 node。

### 验收

`node -v` 输出 v24.9.0 及以上，`npm -v` 有输出。若仍是旧版本：`where node` / `which -a node` 找冲突，先解决再继续。

## 5. 阶段 C：安装 dsh 到自定义文件夹

### C1. 准备目录

- 不存在就创建（只创建，不删除）。
- 已存在且非空：列出来问我，不要清空。
- 不建议放在 OneDrive/网盘同步目录或网络盘，node_modules 会被锁或极慢。

### C2. 写 package.json（不要用 npm init -y）

文件夹名可能含大写或空格，`npm init -y` 会因包名规则失败。直接用 node 写：

```
node -e "require('fs').writeFileSync('package.json', JSON.stringify({name:'deepseek-harness-local',version:'1.0.0',private:true},null,2))"
```

### C3. 查版本并安装

```
npm view @deepseek-ai/dsh dist-tags.latest
npm install @deepseek-ai/dsh@<上一步的版本> --save-exact --no-audit --no-fund
```

- 预计 3–10 分钟、约 1.1 GB，属正常；不要因为慢就中断。
- 国内加速可加 `--registry=https://registry.npmmirror.com`；若该 scope 返回 404，去掉参数用官方源。
- 公司网络证书报错：导入公司根证书并设 `NODE_EXTRA_CA_CERTS`，**不要**关 `strict-ssl`。

### C4. npm 11+ 会拦截安装脚本

看到 `install-scripts ... not yet covered by allowScripts` 时：

1. `npm install-scripts ls`，把清单给我看。
2. 逐条说明用途后再征求同意：
   - `node-pty`：终端伪终端，原生模块（预编译包一般够用）
   - `koffi`：调用系统 API 的 FFI（Windows 上用到）
   - `protobufjs`：生成协议代码
   - `@deepseek-ai/dsh-subprocess-local`：修正可执行位
   - `@google/genai`：空操作脚本
3. 我同意后：

```
npm install-scripts approve --all
npm rebuild @deepseek-ai/dsh-subprocess-local koffi node-pty protobufjs
```

npm < 11 没有这个机制，跳过本节。

### C5. 验收

Windows：`.\node_modules\.bin\dsh.cmd --version`
mac/Linux：`./node_modules/.bin/dsh --version`

应输出版本号（如 `0.2.2-rc.5`）。失败就贴完整报错再分析，不要连试三次不同源。

## 6. 阶段 D：启动并验收

1. 先前台试跑（不自动开浏览器）：

```
.\node_modules\.bin\dsh.cmd web --no-open --port 8787
```

mac/Linux 用 `./node_modules/.bin/dsh web --no-open --port 8787`。

2. 正常会打印一行：`dsh web: http://127.0.0.1:8787/?token=...`
3. 用浏览器打开该完整 URL（token 不能丢），页面标题应为 `DeepSeek Harness`。
4. 命令行复核（Windows PowerShell）：

```
Invoke-WebRequest -Uri "http://127.0.0.1:8787/?token=<token>" -UseBasicParsing | Select-Object StatusCode
```

返回 200 才算通过。通过后 Ctrl+C 结束前台进程，进入阶段 E。

注意：**每次启动 token 都会变**，旧地址会 401，这是正常的。

## 7. 阶段 E：生成一键启动 / 停止脚本

要求：

- 纯 ASCII、无 BOM、CRLF。
- 用 `%~dp0` 相对定位，双击就能跑。
- 端口可传参；启动前检查端口占用。
- 启动脚本等 token 出现后再开浏览器（否则会打开 401 页面）。
- 停止脚本先校验进程身份再杀，绝不 `taskkill /IM node.exe`。
- 自动开浏览器必须是**单独一行**，方便我以后注释掉。

### Windows 参考实现：start-dsh.bat

```bat
@echo off
setlocal EnableExtensions EnableDelayedExpansion
cd /d "%~dp0"
title DeepSeek Harness Launcher

set "PORT=8787"
if not "%~1"=="" set "PORT=%~1"

rem Optional portable data dir (uncomment to keep data in this folder):
rem set "DSH_HOME=%~dp0home"

set "LOGDIR=%~dp0logs"
set "LOGFILE=%LOGDIR%\web.out.log"
set "WAITED=0"
set "WEBURL="

if not exist "%~dp0node_modules\.bin\dsh.cmd" (
    echo [ERROR] node_modules not found. Run "npm install" in this folder first.
    pause
    exit /b 1
)

netstat -ano | findstr /r /c:":%PORT% .*LISTENING" >nul
if not errorlevel 1 (
    echo [ERROR] Port %PORT% is already in use.
    echo         Close the running instance, or use another port:
    echo             start-dsh.bat 8788
    pause
    exit /b 1
)

if not exist "%LOGDIR%" mkdir "%LOGDIR%"
del /q "%LOGFILE%" 2>nul

echo.
echo   DeepSeek Harness - starting Web UI on port %PORT% ...
echo.

start "DeepSeek Harness Web" /min cmd /c ""%~dp0node_modules\.bin\dsh.cmd" web --no-open --port %PORT% > "%LOGFILE%" 2>&1"

:waitloop
if defined WEBURL goto goturl
if %WAITED% GEQ 60 goto timeout
for /f "tokens=3" %%U in ('findstr /l /c:"http://127.0.0.1:%PORT%/?token=" "%LOGFILE%" 2^>nul') do set "WEBURL=%%U"
if defined WEBURL goto goturl
ping -n 2 127.0.0.1 >nul
set /a WAITED+=1
goto waitloop

:goturl
echo   Web UI: !WEBURL!
echo.
rem ---- Auto-open browser. Comment out the next line to disable. ----
start "" "!WEBURL!"

echo   Server is running in the minimized window "DeepSeek Harness Web".
echo   Close that window to stop the server.
echo.
pause
exit /b 0

:timeout
echo   [ERROR] Web UI did not report a URL within %WAITED% seconds.
echo   Log file: "%LOGFILE%"
echo.
type "%LOGFILE%"
pause
exit /b 1
```

### Windows 参考实现：stop-dsh.bat

```bat
@echo off
setlocal EnableExtensions EnableDelayedExpansion
cd /d "%~dp0"
title DeepSeek Harness Stopper

set "PORT=8787"
if not "%~1"=="" set "PORT=%~1"
set "PID="
set "CMDLINE="

for /f "tokens=5" %%P in ('netstat -ano ^| findstr /r /c:":%PORT% .*LISTENING"') do set "PID=%%P"

if not defined PID (
    echo   [INFO] Nothing is listening on port %PORT% - server is not running.
    ping -n 3 127.0.0.1 >nul
    exit /b 0
)

for /f "usebackq delims=" %%C in (`powershell -NoProfile -Command "(Get-CimInstance Win32_Process -Filter 'ProcessId=%PID%').CommandLine"`) do set "CMDLINE=%%C"

if not defined CMDLINE (
    echo   [ERROR] Cannot read the command line of PID %PID%.
    echo           Try running this script as administrator.
    pause
    exit /b 1
)

powershell -NoProfile -Command "if ((Get-CimInstance Win32_Process -Filter 'ProcessId=%PID%').CommandLine -match '@deepseek-ai[\\/]dsh') { exit 0 } else { exit 1 }"
if errorlevel 1 (
    echo   [ERROR] Port %PORT% is held by PID %PID%, which is not a DeepSeek Harness server.
    echo           Command line:
    echo           !CMDLINE!
    echo           Refusing to stop it.
    pause
    exit /b 1
)

echo   Stopping DeepSeek Harness (PID %PID%, port %PORT%) ...
taskkill /F /T /PID %PID% >nul 2>&1

ping -n 3 127.0.0.1 >nul
netstat -ano | findstr /r /c:":%PORT% .*LISTENING" >nul
if not errorlevel 1 (
    echo   [ERROR] Port %PORT% is still listening after the stop attempt.
    echo           Try running this script as administrator.
    pause
    exit /b 1
)

echo   [OK] DeepSeek Harness stopped. Port %PORT% is free.
ping -n 3 127.0.0.1 >nul
exit /b 0
```

写文件时提醒：用 ASCII 编码、不要 BOM；写完逐字节检查一次（存在 >127 的字节就是编码错了）。

### macOS / Linux 等价物

- start：`cd` 到安装目录，`nohup ./node_modules/.bin/dsh web --no-open --port "$PORT" > logs/web.out.log 2>&1 &`，轮询日志拿到 token 后 `open` / `xdg-open`，并把 PID 写进 `run.pid`。
- stop：读 `run.pid`，用 `ps -p <pid> -o command=` 校验包含 `@deepseek-ai/dsh` 再 `kill`；没有 pid 文件时用 `lsof -nP -iTCP:<port> -sTCP:LISTEN -t` 反查，同样先校验再杀。禁止 `pkill node`。

## 11. 我可能提出的额外需求

- **放到别的盘 / 别的文件夹**：只改安装路径，其余步骤不变；路径不要含中文和空格更稳。
- **数据也要一起带走（便携）**：启动脚本里取消 `DSH_HOME` 那行注释，并保证手动运行 dsh 时也设同一个值。
- **远程访问**：不要绑 0.0.0.0、不要开防火墙。用 SSH 隧道 `ssh -L 8787:127.0.0.1:8787 user@host`，或 Tailscale 这类私有网络。token 等同于密码，不要发群里。
- **想用桌面版**：本任务不涉及 Electron；桌面版和 CLI 共用 `~/.dsh` 时注意 profile 名 `desktop` 冲突，先别卸载旧版，验收通过再决定。
