# V1 实现要点

本文记录 AuraBot V1 当前实现，供维护主仓库和排查运行时问题时查阅。V2 的插件接口与消息管线仍在设计阶段，见[插件接口 V2](/reference/plugin-api)。

## 上下文组成

| 项目 | 实现 |
| --- | --- |
| 会话预设 | `cordis.patch.yml` 提供 `aurabot-private` 和 `aurabot-social`。前者用于主人私聊，后者用于群聊和其他用户私聊，不挂本机工具 |
| 人格 | 通过 `@deepseek-ai/dsh-persona` 注入系统提示词，内容取自 `{{aurabot_persona}}` 变量 |
| 动态上下文 | 心情和记忆通过 `agent.ctx.systemPrompt.context()` 追加在对话末尾，不改变系统提示词前缀 |

更换人格只需修改变量内容，不需要重建会话预设。

## 群聊处理

群消息按短时间间隔聚合成对话片段。生成回复期间收到的新消息先保留，下一段再处理，避免逐条打断当前回复。

输入模型的内容包括当前片段、发言人和必要的近期上下文。消息带有编号，合并转发会展开，戳一戳会转换为可处理的事件。被提及时必须回复；其他消息根据话题相关性决定是否参与，并受频率限制。

## 记忆

记忆索引使用中文二元切词和 BM25，并根据当前发言人、重要程度、访问频率和遗忘曲线调整排序。

记忆来源包括：

- 对话中主动保存的事实。
- 定时从聊天记录和 QQ 空间动态整理的内容。
- 点歌、评论等运行记录。
- 空间日记。
- 面板手动添加的内容。

整理记忆时，新事实与旧记录合并；已经失效的记录标记为「已过时」，不直接删除。每个用户、群聊还可以保存人物档案、相处经验和表达习惯。

## 心情

默认根据关键词更新心情，也可以配置为每轮调用模型判断。心情随事件变化，并按半衰期回归常态。

心情会影响语气提示、表情和语音的使用概率、回复速度以及主动插话频率。

## B 站

定时任务根据兴趣配置、用户记忆和面板关键词搜索视频，读取简介、字幕和热门评论，再决定是否评论、私聊分享或写入记忆。WBI 请求按平台规则签名。

系统也会检查已发布评论的回复。主人在 QQ 中发送链接或分享卡片时，可以通过 `bili_watch` 获取视频信息。已浏览和已互动的内容会记录下来。当前实现不执行关注和私信操作。

## 翻唱流程

```text
qq_song_cover 工具
 └─ 获取歌曲音频
     └─ 截取目标片段
         └─ audio-separator 分离人声和伴奏
             └─ Applio（RVC）转换音色
                 └─ FFmpeg 混音
                     └─ 发送语音
```

主仓库不提供音色模型。用户需要自行导入有权使用的 `.pth` 文件或压缩包。安装器使用独立的 Python 环境，支持选择安装位置、显示进度和断点续传。

## 语音

| 方式 | 说明 |
| --- | --- |
| `edge-tts` | 安装在插件独立的 Python 虚拟环境中 |
| 本地模型 | 支持 CosyVoice 和 GPT-SoVITS |
| HTTP 接口 | 可配置地址、方法、请求头和请求体；`{text}` 会转义，`{reqid}` 每次更新；支持解析 JSON 中的 Base64 音频 |
| Windows 语音 | 其他方式不可用时使用系统语音 |

语音输出可以先经过 TTS，再使用翻唱功能导入的 RVC 模型变声。变声失败时使用原始语音。

语音识别优先使用 QQ 的 `fetch_ptt_text`，失败后尝试 DSH 的 `speechToText`。

## 表情包

只收集具有明确表情标识的消息，包括 `sub_type=1`、`mface` 和带 `emoji_id` 的内容。保存前检查尺寸、宽高比、文件体积、MD5 去重和每小时限额。

保存后调用 `add_custom_face`，视觉模型生成备注后再调用 `modify_custom_face`。面板支持修改名称和标签。功能关闭后，回复中的表情也不会发送。

## QQ 空间

空间日记通过 `send_qzone_msg` 发布，在独立后台会话中结合当天聊天记录生成。

互动任务检查自己动态下的评论，并按规定频率浏览好友动态、点赞和评论。同一评论串只处理一次，回复时会参考动态内容和已有评论。

## 模块与运行时

`src/core/modules.js` 负责模块开关、替换、热重载和错误隔离。聊天主流程调用当前正在运行的模块，因此用户可以替换内置模块而不修改核心代码。

| 位置 | 内容 |
| --- | --- |
| `src/modules/` | 内置模块 |
| 数据目录下的 `modules/` | 用户模块；同名模块替换内置实现 |
| 数据目录下的 `local/` | 本地语音、生图、翻唱和识别脚本 |

群聊决策、提示词、回复拆分、发送内容、模型选择、人格和规则均提供改写接口。字段与返回值见[模块 API](/reference/module-api)。

## 会话模型

模型选择优先级为：当前私聊、当前群聊、私聊或群聊默认模型、全局模型。

配置保存在 `config.json` 的 `chatModels` 中，包括 `privateDefault`、`groupDefault`、`privates` 和 `groups`。重启后仍然保留，从对应会话的下一条消息开始生效。只有主人可以修改；模块的 `model` 挂钩随后执行。

## 安全边界

| 项目 | 当前行为 |
| --- | --- |
| 初始状态 | 总开关关闭，试运行开启 |
| 群聊和他人私聊 | 不挂本机工具 |
| 敏感操作 | 要求本轮所有发言者都是主人，执行前再次校验 |
| 危险命令 | 默认关闭；启用后仍需在 QQ 中确认 |
| 管理接口 | 只接受本机回环请求，并进行 CSRF 防护 |
| 反向代理 | 必须同时配置 `trustedProxy` 和 `publicHostname` |

反向代理只应放行面板必需的精确路径，不应开放整个 `/aurabot/api/*`，否则可能暴露没有独立鉴权的模块接口。
