# 设计要点

这篇写给想了解内部实现、或者准备改内核 / 写深度模块的人。只想用的话，看[功能总览](/features/)就够了。

AuraBot 在 DeepSeek Harness 上做了三件事：把人设、心情、记忆放进每一轮上下文；把每一步（回不回、怎么回、发什么、用哪个模型）做成可插拔的模块；把安全默认放在**执行层**而不只是提示词。

## 人格怎么注入

| 方面 | 做法 |
| --- | --- |
| 两个 preset | `cordis.patch.yml` 里自带 `aurabot-private`（主人私聊，完整工具）与 `aurabot-social`（群聊和他人私聊，**没有任何本地工具**） |
| 人格位置 | 通过 `@deepseek-ai/dsh-persona` 放在系统提示词最前，文本来自提示词变量 `{{aurabot_persona}}` |
| 换人格 | 换变量内容，不重建 preset |
| 每轮变化的内容 | 心情与记忆走 `agent.ctx.systemPrompt.context()`，追加在对话末尾，**不破坏前缀缓存** |

## 群聊上下文

群里停顿几秒算一段。她回上一段时，新消息先攒着，看完整段再回——不会一条一回。

交给她的内容是：这一段谁说了什么、之前在聊什么；新消息带编号，想专门接某一条时可以引用回复。合并转发会展开成里面的聊天记录。有人拍她（戳一戳）当成对她说的话，她也能拍回去。

被叫必回，没人叫时按话题相关度插话；有防刷屏的刹车。

## 记忆

本地索引记忆库：中文二元切词 + BM25，再按「关于当前说话人」「重要程度」「遗忘曲线」加权，越常被想起的忘得越慢。

| 来源 | 说明 |
| --- | --- |
| 她自己记的 | 聊天里判断值得记 |
| 每天两次整理 | 从聊天和空间动态里提炼 |
| 她的经历 | 唱了什么、评论了谁 |
| 空间日记 | 每天两条 |
| 手动加的 | 面板或 `/remember` |

整理时新事实先和旧记忆比对：补充旧的就合并，说明旧的过时了就把旧的标成「已过时」（不删，能恢复）。

每个人有一张常驻「人物小档案」，每个人 / 每个群还有「相处经验」和「说话方式」。想起的记忆带时间；对方只说「嗯嗯」时连上一句一起想。

## 心情

默认按关键词判定，可选每轮用模型判一次（有把握才算，能分清她主动找人时的心意）。

被夸、被凶会推动心情，按半衰期回到平常。心情明显时每轮告诉她该怎么说话，并**实际影响**发表情 / 语音的概率、回复快慢、插话积极程度。

## B 站

定时从她的兴趣、记忆里主人喜欢的东西、面板关键词里挑方向搜视频（WBI 签名），读简介、字幕、热评，再按人格决定：评论 / 私聊分享给主人 / 记住什么。

定时看别人回她的评论并接着回。主人在 QQ 里发链接或分享卡片时，她用 `bili_watch` 看完再聊。

看过、评过、回过的都记成她的经历。**不碰关注、私信。**

## 翻唱流水线

```text
点歌（qq_song_cover 工具 或 /sing）
  └─ 网易云下载（weapi，可填 Cookie 下会员歌）
       └─ 先截要发的那一段
            └─ audio-separator 分离人声与伴奏
                 └─ Applio（RVC，固定版本）换成她的音色
                      └─ ffmpeg 混音
                           └─ 发语音条
```

插件不带音色，用户在面板里导入自己有权使用的 `.pth` / zip。一键安装不依赖电脑上的 Python / git / uv，可以选装到哪个盘，进度可见，下载走系统代理并支持断点续传。

## 语音

| 路子 | 说明 |
| --- | --- |
| `edge-tts` | 装在插件自己的 Python 虚拟环境里，三平台都行 |
| 本地模型 | CosyVoice、GPT-SoVITS |
| 任意 HTTP 接口 | 「语音」页的「其他 HTTP 接口」自己填地址、方法、请求头、请求体（`{text}` 自动转义，`{reqid}` 每次换新），返回 JSON（base64）会自动解成音频 |
| Windows 兜底 | 装不上时用系统自带中文语音 |

「语音」页还能用**翻唱里导入的 RVC 音色**给语音条变声：先 TTS 再变声，说话和唱歌同一个声音（翻唱环境要装好；失败自动用原声）。

ASR 先用 QQ 自带的语音转文字（`fetch_ptt_text`），再试 DSH 的 `speechToText`。

## 表情包

只收真正的表情（`sub_type=1`、mface、带 `emoji_id` 的），再过尺寸、宽高比、体积、MD5 去重、每小时限额几道关。

收下后 `add_custom_face`，视觉模型起备注后 `modify_custom_face`。商城表情按原样发；面板能改名字和标签；关掉后回复里写的表情也不发。

## 空间

日记用 `send_qzone_msg`，在专用后台会话里写，结合当天聊天流水。

互动部分：定期看自己说说下的新评论和回复（按整串评论来回，一串只回一次），逛好友动态按概率点赞、评论；评论时结合说说内容和楼里已有的评论。

## 模块与内核

内核在 `src/core/modules.js`：模块的开关、替换、热重载、出错隔离都在这里。

聊天中枢用到表情、语音、心情、记忆时，**找的是当时在跑的那个模块**，所以模块可以整体替换而不改核心。

| 位置 | 内容 |
| --- | --- |
| `src/modules/` | 内置模块 |
| 数据目录 `modules/` | 用户模块，升级不碰，同名即替换 |
| 数据目录 `local/` | 本地接口脚本（语音 / 生图 / 翻唱 / 识别），升级不覆盖，改完即生效 |

聊天主流程留了改写挂钩：群聊决定、提示词、回复拆条、最终发送、模型选择、人格与规则。具体接口见[模块 API 速查](/reference/module-api)。

## 按聊天选模型

优先级：这个私聊 > 这个群 > 所有私聊 / 所有群默认 > 全局模型。

存 `config.json` 的 `chatModels`（`privateDefault`、`groupDefault`、`privates`、`groups`），重启不丢，从那个聊天的下一条消息起生效。只有主人能改；扩展模块的 `model` 挂钩在这之后运行。

## SnowLuma 管理

SnowLuma 的 EULA 第 5.4 条不允许「通过自动化脚本部署」，所以插件**不下载、不替你同意协议**。

| 插件做的 | 插件不做的 |
| --- | --- |
| 显示协议全文，由你本人勾选 | 替你同意 |
| 启停你已经装好的那一份（后台运行，不弹窗） | 下载、安装 |
| 用 `SNOWLUMA_WEBUI_BOOTSTRAP_PASSWORD` 生成控制台密码 | 使用你原来设的密码 |
| 用 `/api/processes` 核对，只注入机器人号 | 注入主号（认不出号时只在唯一一个认不出号的进程上注入，连上后用 `get_login_info` 核对，不是机器人号就断开并撤销） |

`hookAutoLoad` 永远关。

## 安全边界

| 边界 | 做法 |
| --- | --- |
| 默认全关 | 总开关关 + 试运行开 |
| 分场景权限 | 群聊和他人私聊不挂任何本机工具 |
| 敏感操作 | 要求「这一轮说话的人全是主人」，执行前再查 |
| 危险命令 | 默认关；开了要在 QQ 里回「确认」 |
| 管理接口 | 只接受本机回环，带 CSRF 防护 |
| 反代 | 必须同时配 `trustedProxy` 与 `publicHostname`，否则要么形同虚设、要么一保存就 403 |

反代请**只放行面板需要的精确路径**，不要整段 `/aurabot/api/*` 放过去——那会把没有独立鉴权的模块接口一起暴露。
