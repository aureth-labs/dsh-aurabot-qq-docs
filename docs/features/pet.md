# 桌宠

把「大肥鱼」请到桌面上：一个会待在你屏幕角落的小人，主动搭话会冒气泡，点她也能聊天。

**桌宠是社区模块**，1.2.0 起不在主仓库里。所以顺序是：先在面板「模块市场」装，装完「生活 → 桌宠」页才会出现。

## 三个按钮

打开面板「生活 → 桌宠」，按顺序点：

| 步骤 | 按钮 | 耗时 | 说明 |
| --- | --- | --- | --- |
| 1 | 下载 / 生成客户端 | 几秒 | 把桌宠程序生成到数据目录 |
| 2 | 安装 Electron | 1 到 3 分钟 | 约 100 多 MB，走国内镜像；期间按钮可能没反应，等提示出现再动 |
| 3 | 启动桌宠 | 立即 | 桌面上出现大肥鱼就成了 |

第 2 步**不需要你装过 Node、npm 或任何编程环境**：有 npm 就用 npm 装，没有就自动下载官方压缩包解开，全自动判断。

三个按钮都灰着或点了没反应，重启 DSH 再来。

## 平时怎么用

| 操作 | 效果 |
| --- | --- |
| 按住拖动 | 甩到屏幕任意位置，会自己稳住 |
| 左键点她 | 打开聊天 |
| 托盘图标右键 | 退出 |
| 面板「桌宠」页 | 看心跳（在线状态）、点「停止桌宠」 |

「主动搭话走桌宠」这个开关决定她主动找你时是**冒气泡**还是**发 QQ**。

## 手动装 Electron（自动失败时才用）

自动安装一般不会失败；npm 那条路失败时插件会自动改用 zip 直装，不用再点第二次。真反复失败（断网、杀软死拦）就先换「Electron 镜像」再试，还不行再手动：

1. 浏览器打开（整行复制）：

```text
https://npmmirror.com/mirrors/electron/45.1.0/electron-v45.1.0-win32-x64.zip
```

   机器是 ARM 芯片的话，把 `x64` 换成 `arm64`。
2. 下载得到 zip，右键 → 全部解压到任意位置。
3. `Win + R` 输入下面这行，回车：

```text
%USERPROFILE%\.dsh\plugins-data\aurabot\modules-data\pet\app
```

4. 进去后找 `node_modules`（没有就新建，名字原样），把解压出来的文件夹改名成 `electron`，整个拖进去。
5. 回面板点「启动桌宠」。

前提是第 1 步的「下载 / 生成客户端」至少点过一次，`app` 文件夹才存在。

## 面板显示离线，但桌宠明明在跑

先看 DSH 桌面端的「浏览器访问」开关开没开。

它关着的时候，桌宠客户端发出的所有请求（包括心跳）都会被 DSH 当成普通浏览器请求拦下，一律 403——在线状态永远登记不上，**桌宠程序本身没坏**。把开关打开，下一次心跳（半分钟内）就自动上线。

## 对讲

桌宠模块还带一路对讲：`识别 → 她思考 → 合成语音`，全程不经过 QQ。

| 可选项 | 说明 |
| --- | --- |
| `callRvc` + `callRvcVoice` | 关 / 空。开了就在 TTS 出稿后用「翻唱」的音色再变一次声，说话唱歌同一个声音 |
| 变声失败 | 一律**降级为原声，不失败**，失败原因写在本轮返回里 |

## 权限

桌宠模块声明了 `network`、`filesystem`、`process` 等能力——它要起一个 Electron 进程、读写自己的数据。和其它模块一样，这些是声明不是沙箱，装之前看清来源。
