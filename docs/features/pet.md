# 桌宠

桌宠是社区模块，在桌面显示角色、对话气泡和运行状态。安装模块后才会出现「生活 → 桌宠」页面。

## 安装客户端

1. 点击「下载 / 生成客户端」。
2. 点击「安装 Electron」，等待安装完成。
3. 点击「启动桌宠」。

Electron 约需下载 100 MB。安装过程可使用已有的 pnpm，也可由模块下载指定压缩包，不要求用户预先配置完整开发环境。

## 基本操作

| 操作 | 作用 |
| --- | --- |
| 拖动角色 | 调整桌面位置 |
| 左键点击 | 打开聊天 |
| 托盘右键 | 退出 |
| 面板「停止桌宠」 | 结束客户端 |

「主动搭话走桌宠」决定主动消息使用桌面气泡还是平台私聊。

## 手动安装 Electron

自动安装反复失败时，可下载：

```text
https://npmmirror.com/mirrors/electron/45.1.0/electron-v45.1.0-win32-x64.zip
```

ARM64 设备将文件名中的 `x64` 改为 `arm64`。解压后将目录命名为 `electron`，放入：

```text
%USERPROFILE%\.dsh\plugins-data\aurabot\modules-data\pet\app\node_modules\
```

执行此操作前，需要至少生成过一次客户端。

## 在线状态

客户端正在运行但面板显示离线时，检查 DSH 桌面端的「浏览器访问」设置。该设置关闭时，客户端心跳可能被拒绝；开启后等待下一次心跳。

## 对讲与权限

桌宠对讲包含语音识别、模型处理和语音合成，不经过平台聊天。可选的 RVC 处理失败时使用原始 TTS 音频。

模块需要 `network`、`filesystem` 和 `process` 等能力，用于网络通信、数据读写和启动 Electron。能力声明不构成沙箱。
