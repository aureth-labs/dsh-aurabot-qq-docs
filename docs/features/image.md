# 画图

让她发一张图。画图在 AuraBot 里是**工具**，不是指令：你说「画一只猫」，她决定调用画图工具，把图发回来。所以它归「说话 → 画图」页管。

## 先选一条路

内置已经有三条，装了社区模块就是第四条。四条按顺序命中：

| # | 路子 | 要填什么 |
| --- | --- | --- |
| 1 | DSH 已接入的生图模型（社区模块 `dsh-image`） | 在面板里自己选一个模型 |
| 2 | OpenAI 兼容接口 | `baseURL` + `apiKey` + 模型名 |
| 3 | 自定义接口 | 一个能收 `prompt` 返回图片的 HTTP 接口 |
| 4 | Codex 订阅 | 用已登录的订阅额度 |

只有第 1 条会和另外三条打架；第 2、3、4 条谁填得全用谁。

## 内置三条怎么配

面板「说话 → 画图」，从上往下填：

| 字段 | 说明 |
| --- | --- |
| 风格描述（`stylePrompt`） | 会拼在提示词前面。写「动漫赛璐璐上色」比写「画得好看点」有用 |
| 接口地址 | OpenAI 兼容填 `https://.../v1`；自定义接口填完整 URL |
| API Key | 密码字段，写进本机配置，不回显 |
| 模型 | 如 `gpt-image-1`、`doubao-seedream-5-0` |
| 尺寸 / 张数 | 有的接口不支持多张，会直接报错 |

填完点「测试」，能出一张图就通了；出不来就把报错原文贴出来看，比猜快。

## 第四条：用 DSH 已经接好的生图模型

好处是不用另外买额度——DSH 里哪个生图模型能用，这里就能用。

1. 面板「模块市场」搜 `生图`，装 `dsh-image`
2. 面板「说话 → 画图」，最下面「用 DSH 已接入的模型生图」
3. 打开「开启」
4. 点「刷新模型」，在筛选框输入关键词（如 `seedream`、`豆包`）缩小范围
5. **自己选一个模型**，保存

没选模型 = 没接管，照旧走内置那三条。这是故意的：自动挑一个等于替你决定花哪份额度。

模型清单是空的，说明 DSH 里还没接入任何生图模型。先去 DSH 装/登录对应的生图插件（例如豆包插件），回来再点「刷新模型」。

::: warning 会消耗哪份额度
走 DSH 对话模型的生图（比如豆包），扣的是**那个提供方的对话额度**，不是 AuraBot 的画图额度。
:::

## 什么才算生图模型

模块只认明确的生图模型，按 DSH 模型目录里的 id 或名称匹配：

```text
生图 / 绘图 / 图像生成 / Seedream / DALL·E / gpt-image
/ flux / cogview / qwen-image / wanx / grok-imagine
```

普通聊天模型（「豆包 2.1 Pro」）不会混进来，「图片理解」这种能看图但不会画的也不算。

## 怎么用

```text
@她 画一只躺在云上的橘猫
@她 用赛璐璐风格画一张雨天车站，竖版
```

走的是 `qq_draw_image` 工具。带参考图的改画（图生图）不走 DSH 模型这条路——对话模型通道没有统一的编辑协议，会落回内置接法。

## 权限

画图默认只在「这一轮说话的人**全是主人**」时可用。群里有别人在场就不画。想让特定群也能画，去面板「说话 → 权限」把生图那一项放开——放开前先想清楚额度。

## 出不来图怎么查

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 完全不调用工具 | 权限没过，或者她没意识到该画 | 看面板日志有没有 `qq_draw_image`；换成主人私聊再试 |
| 300 / 400 | 接口地址少了 `/v1`，或模型名不对 | 换成官方文档给的完整地址 |
| 401 / 403 | 密钥错，或缺 project / 账号 ID | 重填，注意有些平台要两个字段 |
| 429 | 额度用完或被限流 | 换模型，或等额度恢复 |
| 图很小 / 糊 | 尺寸参数被接口忽略 | 换支持尺寸的模型 |
| 报「模型没选」 | 生图模块开着但没选模型 | 回「画图」页选一个 |
