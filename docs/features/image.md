# 画图

让她发一张图。画图在 AuraBot 里是**工具**，不是指令：你说「画一只猫」，她决定调用画图工具，把图发回来。

## 四条路，按顺序命中

| 顺序 | 路子 | 要填什么 | 稳定性 |
| --- | --- | --- | --- |
| 1 | DSH 已接入的生图模型（社区模块 `dsh-image`） | 在面板里自己选一个模型 | 跟着 DSH 的模型走 |
| 2 | OpenAI 兼容接口 | `baseURL` + `apiKey` + 模型名 | 公开接口，稳 |
| 3 | 自定义接口 | 一个能收 `prompt` 返回图片的 HTTP 接口 | 看你接什么 |
| 4 | Codex 订阅（实验性） | 登录 ChatGPT | 用的是非公开端点，可用性和额度看账号 |

只有第 1 条会和另外三条打架；第 2、3、4 条谁填得全用谁。

## 内置三条怎么配

面板「说话 → 画图」：

| 字段 | 说明 |
| --- | --- |
| 风格描述（`stylePrompt`） | 拼在提示词前面。写「动漫赛璐璐上色」比写「画得好看点」有用 |
| 接口地址 | OpenAI 兼容填 `https://.../v1`；自定义接口填完整 URL |
| API Key | 密码字段，写进本机配置，不回显 |
| 模型 | 如 `gpt-image-1` |
| 默认构图 | 方图 / 竖图 / 横图 / 宽幅，也可以设成「让她选择」 |

填完点「测试」，能出一张图就通了。

### 构图

四档尺寸：

| 构图 | 尺寸 |
| --- | --- |
| 方图 | 1024 × 1024 |
| 竖图 | 1024 × 1536 |
| 横图 | 1536 × 1024 |
| 宽幅 | 1536 × 864 |

这次对话里明确指定的构图优先于面板默认。自定义接口只有写了 `{size}` / `{width}` / `{height}` 才会跟随构图；写死的参数仍按接口配置发。服务不支持尺寸时会如实报错。

## 第四条：用 DSH 已经接好的生图模型

好处是不用另外买额度——DSH 里哪个生图模型能用，这里就能用。

1. 面板「模块市场」搜 `生图`，装 `dsh-image`
2. 面板「说话 → 画图」，最下面「用 DSH 已接入的模型生图」
3. 打开「开启」
4. 点「刷新模型」，在筛选框输入关键词（如 `seedream`、`豆包`）缩小范围
5. **自己选一个模型**，保存

没选模型 = 没接管，照旧走内置那三条。这是故意的：自动挑一个等于替你决定花哪份额度。

清单是空的，说明 DSH 里还没接入任何生图模型。先去 DSH 装/登录对应的生图插件（例如豆包插件），回来再刷新。

::: warning 会消耗哪份额度
走 DSH 对话模型的生图（比如豆包），扣的是**那个提供方的对话额度**，不是 AuraBot 的画图额度。
:::

模块只认明确的生图模型，按 DSH 模型目录里的 id 或名称匹配：

```text
生图 / 绘图 / 图像生成 / Seedream / DALL·E / gpt-image
/ flux / cogview / qwen-image / wanx / grok-imagine
```

普通聊天模型不会混进来，「图片理解」这种能看图但不会画的也不算。

## Codex 订阅（实验性）

在「画图」页选这个接法并登录 ChatGPT，再保存配置。

| 事实 | 说明 |
| --- | --- |
| 用的是非公开图片端点 | 可用性、支持的模型和额度由账号、工作区和服务端决定，不是公开 API 兼容性承诺 |
| 令牌位置 | 单独存 `codex-auth.json`，不进配置、不回面板 |
| 登录 | 本机 1455 回调；端口被占用时可以粘贴完整回调地址 |
| 构图 | 作为提示词引导，实际尺寸由服务端选，不保证严格比例 |
| 退出 | 删掉插件保存的登录信息 |

## 怎么用

```text
@她 画一只躺在云上的橘猫
@她 用赛璐璐风格画一张雨天车站，竖版
```

画完会给她一个**画作编号**（`#1` 是最新那张），编号只在本聊天有效，重启重新算（文件一直都在）。

| 你说 | 她做 |
| --- | --- |
| 用画作 #1 换头像 | 换 QQ 头像 |
| 把画作 #1 存成表情 | 收进表情库 |

带参考图的改画（图生图）不走 DSH 模型这条路——对话模型通道没有统一的编辑协议，会落回内置接法。

## 群里的生图权限

默认只在「这一轮说话的人**全是主人**」时才画。

有个例外：群里主人真正 @ 她或引用回复她提出画图请求时，同批普通群友消息不会误拦生图。但**多个人同时 @ / 引用提请求就要分开发**。主人只是参与闲聊不会让群友获得权限，授权也不沿用到下一轮。

这个例外只用于生图，不改变改资料、发文件等操作的权限。

## 让她画完自己看一眼

支持视觉的模型可以收到刚画好的图。大图需要本机 `ffmpeg` 缩图；缩图或附件服务不可用时她会如实说没看到。

把「让她画完自己看一眼」关掉、或「视觉能力」选「不支持」时，画完只回一句「画好了」。

## 出不来图怎么查

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 完全不调用工具 | 权限没过，或她没意识到该画 | 看日志有没有 `qq_draw_image`；换主人私聊再试 |
| 300 / 400 | 接口地址少了 `/v1`，或模型名不对 | 换成官方文档给的完整地址 |
| 401 / 403 | 密钥错，或缺 project / 账号 ID | 重填 |
| 429 | 额度用完或被限流 | 换模型或等额度 |
| 图很小 / 糊 | 尺寸参数被接口忽略 | 换支持尺寸的模型 |
| 报「模型没选」 | 生图模块开着但没选模型 | 回「画图」页选一个 |
