# 画图

画图功能通过模型工具生成并发送图片。可以使用 DSH 已接入的生图模型，也可以配置独立接口。

## 接入方式

| 方式 | 必要配置 | 说明 |
| --- | --- | --- |
| DSH 生图模型 | 安装社区模块并明确选择模型 | 使用 DSH 中已有的模型配置 |
| OpenAI 兼容接口 | 基础 URL、API Key 和模型 ID | 使用公开接口 |
| 自定义 HTTP 接口 | 接收提示词并返回图片的接口 | 请求结构由用户配置 |
| Codex 订阅 | 登录 ChatGPT | 实验性，使用非公开端点 |

## 基本配置

「说话 → 画图」中的常用字段：

| 字段 | 说明 |
| --- | --- |
| `stylePrompt` | 添加到提示词前部的风格要求 |
| 接口地址 | 兼容接口的基础 URL 或自定义接口完整 URL |
| API Key | 保存在本机配置中 |
| 模型 | 例如 `gpt-image-1` |
| 默认构图 | 方图、竖图、横图、宽幅或由模型选择 |

保存前使用「测试」验证接口。

| 构图 | 尺寸 |
| --- | --- |
| 方图 | 1024 × 1024 |
| 竖图 | 1024 × 1536 |
| 横图 | 1536 × 1024 |
| 宽幅 | 1536 × 864 |

对话中明确指定的构图优先于默认值。自定义接口只有包含相应尺寸占位符时才会接收构图参数。

## 使用 DSH 生图模型

1. 在模块市场安装 `dsh-image`。
2. 在「画图」中启用「用 DSH 已接入的模型生图」。
3. 刷新模型列表并选择一个生图模型。
4. 保存配置。

未选择模型时，该模块不会接管生图。列表为空表示 DSH 尚未提供可识别的生图模型。

此方式消耗对应模型提供商的额度，具体计费以该提供商为准。

## Codex 订阅

此方式使用非公开图片端点，可用模型、额度和输出尺寸由账号及服务端决定。登录信息单独保存在 `codex-auth.json`，不写入普通配置。

本机登录默认使用 1455 端口接收回调。端口被占用时，可粘贴完整回调地址。

## 生成结果

生成图片会获得当前聊天内的编号，例如 `#1`。可以用于更换头像或保存为表情；编号在重启后重新计算，图片文件仍保留在数据目录中。

图生图不通过 DSH 对话模型通道处理，因为该通道没有统一的图片编辑协议。

## 权限与视觉检查

群聊生图默认要求本轮发言者均为主人。主人直接 @ 或引用机器人提出请求时，可按当前实现处理同批消息，但授权不会延续到后续对话。

支持图片输入的模型可以接收生成结果进行检查。缩图依赖 FFmpeg；无法读取图片时，模型应明确说明。

## 排查

| 现象 | 检查项 |
| --- | --- |
| 没有调用画图工具 | 权限、模块状态和日志中的 `qq_draw_image` |
| `300`、`400` | 基础 URL、模型 ID 和请求参数 |
| `401`、`403` | 密钥及账号权限 |
| `429` | 额度或频率限制 |
| 输出尺寸不符合要求 | 模型是否支持尺寸参数 |
| 提示未选择模型 | `dsh-image` 已启用但没有选择具体模型 |
