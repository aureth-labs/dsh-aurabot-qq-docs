# QQ 空间

面板「生活 → QQ 空间」。她能写说说、回评论、逛好友动态。

## 写日记

| 设置 | 说明 |
| --- | --- |
| 每天几条 | 默认两条 |
| 写什么 | 结合当天聊天流水写，专用后台会话，不占用聊天上下文 |
| 谁能看 | 所有人 / 好友 / 部分好友可见 / 部分好友不可见 / 仅自己 |
| 日记配图 | 开着时每篇从「今天她画的图」或「今天收的表情包」里挑一张，没有合适的就只发文字 |

::: warning 两个「部分好友」要填名单
选了「部分好友可见」或「部分好友不可见」而名单为空时，**她不会发**，也不会退回公开。这是故意的：宁可少发一篇，也不要发错范围。
:::

在聊天里让她发说说时，她只能把范围**收窄成「仅自己」**，不能扩大你在面板里定的范围。

想立刻写一篇：「QQ 空间」页点「现在写一篇」，或者在 QQ 里发 `/diary`。

## 回评论

有人评论她的说说会回；接着回她也会接着聊。逛好友动态时偶尔点赞、评一句——这两个行为在「空间日记」页打开。

评论时会结合说说内容和楼里已有的评论，不是自顾自说一句。

## 和记忆的关系

空间日记会进记忆库，成为她的「经历」。所以她会记得「前天写过一篇关于下雨的说说」，而不是每天从零开始。

## 常见情况

| 现象 | 原因 |
| --- | --- |
| 一篇都没发 | 空间总开关关着；或「部分好友」名单为空 |
| 发了但没人看得到 | 可见范围设成了「仅自己」 |
| 配图总是同一张 | 当天只画了一张图；换一张或关掉配图 |
| 评论回得很生硬 | 评论走的是人格，改人格比改这里有用 |
| 不想让她逛别人动态 | 「空间日记」页关掉互动那个开关 |
