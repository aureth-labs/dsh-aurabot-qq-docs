# QQ 空间

QQ 空间功能位于「生活 → QQ 空间」，用于发布说说、处理评论和浏览好友动态。

## 日记

| 配置 | 说明 |
| --- | --- |
| 每天几条 | 默认两篇 |
| 内容来源 | 当天聊天流水和专用后台会话 |
| 可见范围 | 所有人、好友、指定好友或仅自己 |
| 日记配图 | 从当天生成图片或收集表情中选择 |

选择「部分好友可见」或「部分好友不可见」时，必须填写名单。名单为空会阻止发布，不会自动改为公开。

聊天中发起的发布请求只能收窄可见范围，不能突破面板中的限制。

使用「现在写一篇」或 `/diary` 可立即生成日记。

## 评论与互动

功能可以处理说说下的新评论，并按配置浏览好友动态、点赞或评论。生成评论时会读取说说正文和已有评论。

日记可写入记忆，供后续对话检索。

## 排查

| 现象 | 检查项 |
| --- | --- |
| 没有发布日记 | 总开关和指定好友名单 |
| 其他人无法查看 | 可见范围 |
| 总是使用同一配图 | 当天候选图片数量 |
| 评论风格不合适 | 人格配置 |
| 不希望浏览好友动态 | 关闭对应互动开关 |
