# 表情包

表情包功能负责收集、标注和发送收藏表情。配置位于「说话 → 表情包」。

## 收集条件

系统只处理符合表情特征的图片，并检查类型、尺寸、宽高比和文件大小。相同内容按 MD5 去重，每小时的收集数量也有限制。

收集后可使用视觉模型生成名称和标签，再在面板中修改。

## 收集模式

| 模式 | 行为 |
| --- | --- |
| 全都偷 | 自动收集符合条件的表情 |
| 她挑 | 提供候选，由模型选择是否收集 |
| 只听主人的 | 只在主人场景提供收集提示 |

后两种模式的候选可暂存 30 分钟，重启后仍可恢复，但有效期不会延长。

## 使用与管理

| 操作 | 方法 |
| --- | --- |
| 收集最近图片 | 发送「存一下刚才的表情」 |
| 保存生成图片 | 发送「把画作 #1 存成表情」 |
| 修改名称或标签 | 在「表情包」页面编辑 |
| 停止发送表情 | 关闭表情包总开关 |

每个聊天保留最近 6 张图片的短期引用，引用有效期为 30 分钟。原图失效后需要重新发送。

QQ 小黄脸可随文字一起发送，也可以在「表情包」页面单独关闭。

## 排查

| 现象 | 检查项 |
| --- | --- |
| 没有收集表情 | 收集模式、白名单和图片类型 |
| 已收集但无法发送 | 模块开关和 QQ 收藏容量 |
| 名称仍为编号 | 视觉模型配置，或手动修改名称 |
| 图片无法显示 | 商城表情是否过期 |
