# 表情包

她会自己收表情、给表情起名字，再按语境挑一个发出来。商城表情按原样发，动画由 QQ 自己播。

面板「说话 → 表情包」。

## 只收真正的表情

不是见到图就存。要过这几道关：

| 关卡 | 说明 |
| --- | --- |
| 类型 | `sub_type=1`、mface、带 `emoji_id` 的才算；普通照片不收 |
| 尺寸 | 太大太小都跳过 |
| 宽高比 | 太扁太长的不收 |
| 体积 | 超过上限不收 |
| 去重 | 按 MD5 去重 |
| 频率 | 每小时有收取限额 |

收下之后存进 QQ 收藏表情，再用视觉模型起个备注，最后改一次名字和标签。

## 三种「怎么偷」

面板「表情包 → 怎么偷」：

| 模式 | 行为 |
| --- | --- |
| 全都偷（默认） | 看到就收 |
| 她挑 | 只记下来并给她一句轻提示，她喜欢才按编号收 |
| 只听主人的 | 只在主人私聊、或这一轮只有主人说话时提示她收；有别人在场时她不能自己收，要主人发话 |

后两种模式下，表情会暂存 30 分钟（重启不丢），她可以用 `qq_collect_sticker` 按编号收，也能收自己刚画的图。

## 怎么用

| 你想 | 说 |
| --- | --- |
| 让她存刚收到的表情 | 「存一下刚才的表情」 |
| 让她把画作存成表情 | 「把画作 #1 存成表情」 |
| 改名字 / 标签 | 面板「表情包」页，鼠标移到表情上点名字或标签，改完点别处就保存 |
| 全关掉 | 「表情包」页的总开关，关了她一张都不发 |

「存一下刚才的表情」取的是本聊天**最近收到的图**：每个聊天保留最近 6 张的短期引用，有效期从收到时起算 30 分钟，重启可以恢复但不延长。图本身已经失效时要重新发。

## QQ 小黄脸

她会在文字里夹 QQ 自带的表情（`/捂脸` `/斜眼笑` `/吃瓜`），和文字在同一条消息里；别人发来的小黄脸她也认得出是哪个。

不想要就在「表情包」页关掉「夹 QQ 小黄脸」——关掉后她只发收藏的表情包，不发小黄脸。

## 关掉之后会怎样

表情包模块一关，回复里写的 `<sticker:名字>` 也不会发出去，只留文字。自带的 `/捂脸` 这类也一起停（取决于小黄脸那个开关）。

## 排查

| 现象 | 原因 |
| --- | --- |
| 收不到表情 | 「全都偷」没开，或者群不在白名单 |
| 收了但发不出来 | 表情模块被关，或者 QQ 收藏表情已满 |
| 表情名字是编号 | 视觉模型没配好，起名那步跳过了；面板里手动改 |
| 发出去变成裂图 | 商城表情过期了，换一个 |
