# 记忆

她的记忆不是「聊天记录全文塞进上下文」，而是一个本地索引的记忆库：写进去、按相关度取出来、越常被想起越难忘。

## 记忆从哪来

| 来源 | 什么时候写 |
| --- | --- |
| 她自己记的 | 聊天里觉得该记住的事，她自己决定写 |
| 每天整理两次 | 默认 4 点和 16 点，把聊天提炼成长期记忆 |
| 她的经历 | 唱了什么歌、评论了谁、看了什么视频 |
| 空间日记 | 每天两条说说 |
| 你手动加的 | 面板里直接写，或者 QQ 里发 `/remember 内容` |

## 怎么取出来

检索是「中文二元切词 + BM25」，再按三件事加权：

| 权重 | 作用 |
| --- | --- |
| 关于当前说话人 | 聊到谁就优先想跟谁有关的事 |
| 重要程度 | 你标重要的更容易被想起 |
| 遗忘曲线 | 越常被想起的忘得越慢 |

几个细节：

- 想起的记忆**带时间**，所以她会说「上次你说……」而不是当成刚发生
- 对方只回「嗯嗯」时，会把上一句一起想起来
- 面板能看到最近几轮想起了哪几条

## 整理时怎么处理冲突

新事实先和旧记忆比对：

| 情况 | 处理 |
| --- | --- |
| 补充旧记忆 | 合并成一条 |
| 说明旧记忆过时了 | 旧的标成「已过时」，**不删**，可以恢复 |

## 人物档案

每个人一张常驻的「人物小档案」，每个群还有「相处经验」和「说话方式」。这些都在面板「生活 → 人物记忆」页，能看也能改。

| 东西 | 管什么 |
| --- | --- |
| 人物画像 | 这个人是谁、什么脾气、在意什么 |
| 群印象 | 这个群是什么氛围、谁跟谁熟 |
| 相处经验 | 跟这个人/这个群相处下来学到的规矩 |
| 说话方式 | 在这个场景里该怎么措辞 |

## 容量

面板「说话 → 心情与记忆」里能调**自动记忆容量**：默认 3000 条，最多 100000 条。

```text
聊天提炼 / 经历 / 日记  → 按各自配额分配
手动记忆 / 分档事实     → 不受容量限制
```

提高容量不会关掉已有的过期与压缩规则——那些规则是防止上下文被撑爆的，关了反而更慢。

## 导入旧档案

换电脑或者从别的框架迁过来时，可以导入旧档案：

1. 面板「心情与记忆」页找导入入口
2. 选文件，导入后可以在「人物记忆」页核对
3. 导入不影响现有记忆，重复的会合并

## 排查

| 现象 | 原因 |
| --- | --- |
| 她完全不记得昨天的事 | 「心情与记忆」页的记忆总开关关了，或整理时间还没到 |
| 记得很多但说不出来 | 上下文预算被占满，调低每轮召回条数 |
| 人物档案是空的 | 还没到整理时间；或者这个人在白名单外的群里 |
| 改了一条记忆没生效 | 记忆是索引结构，改完要等下一轮才重新检索 |
