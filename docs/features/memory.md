# 记忆

记忆功能将信息保存到本地索引，在后续对话中按相关度检索。它与完整聊天记录不同，也不会默认全部放入模型上下文。

## 信息来源

| 来源 | 写入方式 |
| --- | --- |
| 对话整理 | 默认每天 4 点和 16 点提炼长期信息 |
| 主动记录 | 对话中判断需要保存的信息 |
| 功能经历 | 点歌、评论、浏览视频等操作记录 |
| 空间日记 | 已发布的日记内容 |
| 手动添加 | 面板编辑或 `/remember 内容` |

## 检索方式

当前实现使用中文二元切词与 BM25，并结合以下因素排序：

| 因素 | 作用 |
| --- | --- |
| 当前说话人 | 优先检索与当前用户相关的信息 |
| 重要程度 | 提高标记为重要的记忆权重 |
| 访问时间 | 按遗忘曲线调整权重 |

检索结果包含时间信息。简短回复还可能结合上一条消息一起检索。面板可查看最近使用的记忆条目。

## 更新与冲突

新信息补充旧记忆时进行合并；新信息使旧内容失效时，将旧内容标记为「已过时」，不直接删除。

人物档案保存用户信息，群档案保存群印象、相处经验和说话方式。这些内容可在「人物记忆」中查看和修改。

## 容量

「心情与记忆」中的自动记忆容量默认是 3000 条，可调整到最多 100000 条。

自动整理的内容按类别分配容量；手动记忆和特定分档事实不受该上限约束。提高容量不会关闭过期和压缩规则。

## 导入与排查

导入旧档案后，可在「人物记忆」中核对结果。重复内容会合并。

| 现象 | 检查项 |
| --- | --- |
| 无法回忆较早内容 | 记忆总开关、整理时间和索引状态 |
| 检索结果未进入回复 | 上下文预算和每轮召回条数 |
| 人物档案为空 | 是否已执行整理，来源聊天是否在白名单内 |
| 修改后没有立即变化 | 等待下一轮重新检索 |
