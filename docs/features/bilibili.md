# 刷 B 站

面板「生活 → B 站」。她会自己挑视频看、写评论、把好玩的私聊分享给你，还会看别人回她的评论接着回。

## 她怎么挑视频

```text
兴趣 + 记忆里你喜欢的东西 + 面板里填的关键词
   └─ WBI 签名搜索
        └─ 读简介 / 字幕 / 热评
             └─ 按人格决定：评论 / 私聊分享 / 记住什么
```

看过、评过、回过的都会记成她的**经历**，所以她会说「上次那个讲深海鱼的视频」。

**不碰关注，不碰私信。** 只做搜索、观看、评论、分享这四件事。

## 你在 QQ 里给她链接

私聊或群里发一条 B 站链接、或者分享卡片，她会用 `bili_watch` 看完再跟你聊——不是只念一遍标题。

## 让她看画面（默认关闭）

打开后每个视频抽 2 到 12 帧，画面描述会和字幕、简介、热评一起交给她读。

| 前提 | 说明 |
| --- | --- |
| `ffmpeg` | 没有就抽不了帧，会继续只读文字 |
| 支持图片的模型 | 模型明确不支持图片时同样退回文字 |
| 截图库 | 默认保留最近 300 张，可在面板预览、删除、调上限 |

聊天里说「有哪些截图」「发张刚才那个视频的截图」，她会按标题或画面备注挑一张发到当前会话。

定时刷完默认有 35% 概率向主人私聊发一张截图，调成 0 就不自动发。试运行不会实际发送，也不会报告说已经发了。

## 发弹幕

弹幕在「B站」页底部，不需要额外装扩展，登录沿用 B 站页保存的 Cookie。

| 开关 | 默认 | 作用 |
| --- | --- | --- |
| `bili.danmakuEnabled` | 关 | 面板、聊天工具、自动弹幕的**实际发送**总闸 |
| `bili.autoDanmaku` | 关 | 刷完视频后是否**自动**发一条；两个都开才生效 |
| `bili.maxDanmakuPerDay` | 3 | 1 到 20，手动与自动共用这个上限 |

几个硬规矩：

- 一行有效文字，最多 100 个 Unicode 字符，不截断 emoji
- 支持滚动、顶部、底部三种，不做高级弹幕样式
- 改完设置**先保存**；总开关或 B 站关着时不发
- 试运行不提交、不消耗次数、不写成功记忆
- 提交前会再检查一次登录态、开关、模块是否还在跑

### 「检查视频」不花额度

它只读标题、当前 CID 和时长，不发弹幕、不消耗次数。

支持 `BV` / `av` 号、完整视频链接、`ep` 单集、`ss` 整季链接；短链接要先展开。

「分P / 选集序号」怎么填：

| 情况 | 填什么 |
| --- | --- |
| 普通单段投稿 | `1` |
| 多段投稿 | 分P 序号，以该分P的 CID 和时长为准 |
| `ss` 整季链接 | 主选集列表里的第几集 |
| `ep` 链接 | 直接定位那一集，不用填序号 |

出现时间按当前分P或单集算，单位秒，可以填 `0.1` 这种小数。

### 手动发弹幕

主人在私聊里通过 `bili_danmaku` 工具指定链接、正文、时间、分P。工具挂载与执行都查身份，**不向群聊或普通用户开放**。

自动弹幕只用本轮视频标题和浏览感想，并且禁止工具调用；没合适内容就不发，每个视频每天最多自动发一次。

### 失败与重试

| 情况 | 行为 |
| --- | --- |
| 提交前 | 先写一条待确认记录 |
| 24 小时内同 CID + 时间 + 内容 | 不重复提交 |
| 两次提交之间 | 至少隔 30 秒 |
| 风控 / 验证码 / 频率限制 | 暂停弹幕 30 分钟，**不自动解验证码** |
| 超时或没返回编号 | 提示「结果未确认」，让你先去 B 站看一眼，避免重复发 |

只有平台返回 `code: 0` 和有效弹幕编号才算成功。大整数编号优先用平台的 `dmid_str`，不从丢失精度的数字里猜。平台接收不等于所有观众立刻可见，面板里可以展开响应看 `visible` 等结果。

历史写在模块数据目录的 `danmaku.json`，不进源码仓库。面板只展示允许公开的响应字段，不回传请求头或 Cookie。

## 评论被暂停了怎么恢复

登录失效会导致当天评论暂停，以前换了新 Cookie 也要等到次日。现在：

1. 保存新的有效 Cookie
2. 点「检查登录」，确认还是同一份凭证
3. 登录 / CSRF 错误导致的暂停会解除，原有次数和历史保留

风控、验证码、频率限制**不会**因为登录核验成功而解除。同一份凭证再被写接口拒绝一次，也不会反复解暂停。

## 排查

| 现象 | 原因 |
| --- | --- |
| 她完全不刷 | B 站模块关着，或者总开关关着 |
| 刷了但不评论 | 评论那条开关关着，或者模型判定不值得评 |
| 弹幕发不出去 | `danmakuEnabled` 没开；或当天额度用完 |
| 一直提示「结果未确认」 | 平台超时，去 B 站看有没有发出去，别连着重试 |
| 截图功能没反应 | 缺 `ffmpeg`，或模型不支持图片 |
