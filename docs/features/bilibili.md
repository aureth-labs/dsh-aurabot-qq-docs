# 刷 B 站

B 站功能位于「生活 → B 站」，包括视频搜索、内容阅读、评论、私聊分享和弹幕。

## 视频处理

搜索结合人格、记忆和面板关键词，通过 WBI 签名请求获取候选，再读取简介、字幕和热评。浏览、评论和回复记录可作为经历写入记忆。

当前功能不处理关注和平台私信。

在聊天中发送视频链接或分享卡片，可调用 `bili_watch` 读取视频信息后参与对话。

## 画面读取

开启画面读取后，每个视频可抽取 2 到 12 帧，与文字资料一起提供给模型。

| 条件 | 说明 |
| --- | --- |
| FFmpeg | 用于抽帧；缺失时只处理文字 |
| 视觉模型 | 不支持图片时只处理文字 |
| 截图存储 | 默认保留最近 300 张，可在面板管理 |

聊天中可以请求查看或发送已有截图。定时浏览后可按配置概率向主人私聊发送截图；试运行不会实际发送。

## 弹幕

弹幕使用 B 站页面保存的 Cookie。

| 配置 | 默认值 | 作用 |
| --- | --- | --- |
| `bili.danmakuEnabled` | 关 | 控制所有实际弹幕发送 |
| `bili.autoDanmaku` | 关 | 控制浏览后自动发送 |
| `bili.maxDanmakuPerDay` | 3 | 手动和自动共用每日上限，可设 1 到 20 |

正文最多 100 个 Unicode 字符，支持滚动、顶部和底部弹幕。试运行不提交请求，也不消耗次数。

「检查视频」只读取标题、CID 和时长。支持 BV 号、av 号、视频链接、`ep` 和 `ss` 链接；多分 P 内容需要按页面规则选择序号。

手动弹幕通过 `bili_danmaku` 调用，仅向主人私聊开放。自动弹幕根据当前视频内容生成，没有合适内容时不发送。

## 重试与限制

- 同一 CID、时间和正文在 24 小时内不重复提交。
- 两次提交至少间隔 30 秒。
- 遇到风控、验证码或频率限制时暂停 30 分钟，不自动处理验证码。
- 超时或没有返回编号时标记为「结果未确认」，应先到 B 站核对。
- 只有平台返回 `code: 0` 和有效弹幕编号才记为成功。

历史保存在模块数据目录的 `danmaku.json`。面板不展示 Cookie 或请求头。

## 登录恢复

更新 Cookie 后，保存并执行「检查登录」。登录或 CSRF 错误造成的暂停可解除；风控、验证码和频率限制不会因此解除。

## 排查

| 现象 | 检查项 |
| --- | --- |
| 没有定时浏览 | B 站模块和总开关 |
| 浏览后没有评论 | 评论开关和模型判断 |
| 弹幕未发送 | 总开关、自动开关和每日额度 |
| 结果一直未确认 | 先在 B 站核对，避免重复提交 |
| 没有画面读取 | FFmpeg 和模型图片输入能力 |
