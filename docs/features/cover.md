# 翻唱

用你导入的音色唱一首，做成语音条发出来（约一分钟）。翻唱是 AuraBot 的**内置模块**，位置在面板「生活 → 翻唱」。

底子是 RVC（Applio，固定版本）。它有两个前提：**环境**和**音色**。

::: warning 只有 Windows 能用
RVC 这条链路目前只在 Windows 跑通，Linux / macOS 装得上但转换会失败。见[常见问题](/guide/faq)。
:::

## 完整流水线

```text
点歌（qq_song_cover 工具 或 /sing）
  └─ 网易云下载（weapi，可填 Cookie 下会员歌）
       └─ 先截要发的那一段
            └─ audio-separator 分离人声与伴奏
                 └─ Applio（RVC）换成她的音色
                      └─ ffmpeg 混音
                           └─ 发语音条
```

所以翻唱不是「直接换嗓子」，中间有分离和混音。这也是为什么它比 TTS 慢得多。

## 三步走

1. **装环境**：翻唱页上有一键安装，不依赖电脑上的 Python / git / uv，可以选装到哪个盘，进度可见，下载走系统代理并支持断点续传
2. **导音色**：导入或训练成音色，`.pth` / zip；插件**不带任何音色**
3. **选音色**：在翻唱页选当前音色并保存

选中的音色是全局的——点歌翻唱用它，语音条变声也用它。

## 怎么用

| 你说 | 她做 |
| --- | --- |
| 「唱一首晴天」 | 走点歌 → 翻唱流水线 |
| `/sing 晴天` | 同上，指令直达 |
| 什么都不说 | 语音条自动用翻唱音色变声（如果开了那个开关） |

翻唱完会触发 `song/sung` 事件，别的模块可以接。

## 音色从哪来

| 来源 | 做法 | 注意 |
| --- | --- | --- |
| 别人的现成模型 | 下载 `.pth` + `.index` 放进音色目录 | 只放你确定有授权的 |
| 自己录 | 一段几十秒到几分钟的干净人声，按页面提示训练 | 训练要时间，CPU 上很慢 |

干声的要求很朴素：**只有人声，没有伴奏、没有混响、没有削波**。手机在衣柜里录都比在客厅录好。

## 失败一律降级

翻唱没就绪时，语音条**退回原声**照常发出，不报错。所以「怎么没变声」通常在日志里：

```text
翻唱模块没就绪，这一轮没变声（原声）
翻唱里没有音色「X」，这一轮没变声（原声）
变声失败，用原声：<具体报错>
```

## 排错

| 现象 | 原因 |
| --- | --- |
| 「读不了某个模型文件」 | 多半是杀毒软件（360、火绒、Defender）拦住了。把翻唱目录加进信任区；还不行就删掉那个文件重新下载 |
| 人声分离模型下不动 | 安装会自动换国内镜像、断点续传；还不行就照面板给的地址用浏览器下好，拖进「音色模型」框 |
| 环境装了但转换报 `ModuleNotFoundError` | 依赖没装全，回页面点「重新检查」照提示补 |
| 转换卡住不动 | CPU 跑大模型，等；或音色 `.index` 缺失 |
| 出来是杂音 / 电流声 | 干声太差，或音高设置不对，先换个音色试 |
| 唱歌正常、语音条不变声 | 语音条那侧走的是 TTS 再变声，先确认 TTS 通 |
| 换了音色没变化 | 没保存，或者那一条是缓存的旧音频 |
