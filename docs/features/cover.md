# 翻唱

翻唱功能使用 RVC 音色处理歌曲，并发送生成的语音。V2 的「翻唱」插件管理制作环境、音色、队列和会话投递。面板可以试唱到某个平台的主人私聊。

::: warning 平台限制

内置制作环境体积为数 GB，需要在面板主动安装。使用其他制作服务时，可由该服务提供音频。接收机器人的适配器需要支持语音。
:::

## 处理流程

```text
点歌
  └─ 获取歌曲音频
       └─ 截取目标片段
            └─ audio-separator 分离人声与伴奏
                 └─ Applio（RVC）转换音色
                      └─ FFmpeg 混音
                           └─ 发送语音
```

该流程包含多个音频处理步骤，因此耗时明显长于普通 TTS。

## 配置

1. 在翻唱页面安装运行环境。
2. 导入有权使用的 `.pth`、`.index` 或音色压缩包。
3. 选择当前音色并保存。

插件不分发音色模型。自行录制训练数据时，应尽量保证只有清晰人声，没有伴奏、混响和削波。

## 触发方式

| 输入 | 行为 |
| --- | --- |
| 「唱一首晴天」 | 通过工具执行点歌和翻唱 |
| 语音条变声 | 对 TTS 音频使用当前翻唱音色 |

在插件配置里打开「注册指令」后，可用 `/sing 晴天 开始=30 时长=8` 点唱片段。制作期间切换登录账号、关闭插件或收回权限，原任务会停止投递。语音确认送达后触发 `song/sung`，事件包含目标会话和歌名。

## 降级

RVC 未就绪或转换失败时，语音功能使用原始音频继续发送，并在日志中记录原因。没有变声时先检查日志，而不是重复发送请求。

## 排查

| 现象 | 检查项 |
| --- | --- |
| 模型文件无法读取 | 杀毒软件拦截或文件损坏 |
| 分离模型无法下载 | 网络、镜像和手动导入方式 |
| `ModuleNotFoundError` | 运行环境依赖不完整 |
| 转换长时间不结束 | CPU 性能和音色索引文件 |
| 输出有杂音 | 训练干声质量和音高设置 |
| 翻唱正常但语音不变声 | TTS 和语音条变声配置 |
| 更换音色后无变化 | 是否保存，以及是否使用缓存音频 |
