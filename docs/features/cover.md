# 翻唱

翻唱功能使用 RVC 音色处理歌曲，并发送生成的语音。它是 AuraBot V1 的内置模块，配置位于「生活 → 翻唱」。

::: warning

平台限制

当前 RVC 流程仅在 Windows 验证通过。
:::

## 处理流程

```text
点歌
  └─ 获取歌曲音频
       └─ 截取目标片段
            └─ audio-separator 分离人声与伴奏
                 └─ Applio（RVC）转换音色
                      └─ FFmpeg 混音
                           └─ 发送语音
```

该流程包含多个音频处理步骤，因此耗时明显长于普通 TTS。

## 配置

1. 在翻唱页面安装运行环境。
2. 导入有权使用的 `.pth`、`.index` 或音色压缩包。
3. 选择当前音色并保存。

插件不分发音色模型。自行录制训练数据时，应尽量保证只有清晰人声，没有伴奏、混响和削波。

## 触发方式

| 输入 | 行为 |
| --- | --- |
| 「唱一首晴天」 | 通过工具执行点歌和翻唱 |
| 语音条变声 | 对 TTS 音频使用当前翻唱音色 |

完成后会触发 `song/sung` 事件，供其他模块监听。

## 降级

RVC 未就绪或转换失败时，语音功能使用原始音频继续发送，并在日志中记录原因。没有变声时先检查日志，而不是重复发送请求。

## 排查

| 现象 | 检查项 |
| --- | --- |
| 模型文件无法读取 | 杀毒软件拦截或文件损坏 |
| 分离模型无法下载 | 网络、镜像和手动导入方式 |
| `ModuleNotFoundError` | 运行环境依赖不完整 |
| 转换长时间不结束 | CPU 性能和音色索引文件 |
| 输出有杂音 | 训练干声质量和音高设置 |
| 翻唱正常但语音不变声 | TTS 和语音条变声配置 |
| 更换音色后无变化 | 是否保存，以及是否使用缓存音频 |
