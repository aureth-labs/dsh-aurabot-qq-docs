# 翻唱

让她的声音变成某个人的声音去唱。翻唱是 AuraBot 的**内置模块**，不是社区模块，位置在面板「生活 → 翻唱」。

底子是 RVC（Retrieval-based Voice Conversion）：先有一段干声，再用音色模型把它换掉。所以它有两个前提——**环境**和**音色**。

::: warning 只有 Windows 能用
RVC 这条链路目前只在 Windows 上跑通。Linux / macOS 能装能开，但转换会失败，见[常见问题](/guide/faq)。
:::

## 三步走

1. **装环境**：翻唱页上有环境检查，缺什么它列什么。通常是 Python 和几个 pip 包。
2. **导音色**：准备一段干净的干声（没人声混响、没有伴奏），导入或训练成音色。
3. **选音色**：在翻唱页选一个当前音色，保存。

选中的音色是全局的——点歌翻唱用它，语音条变声也用它。

## 环境检查看什么

| 项 | 缺了会怎样 |
| --- | --- |
| Python | 环境检查直接红，什么都跑不了 |
| pip 依赖（torch / fairseq / 之类） | 能进页面，一开始转换就报 `ModuleNotFoundError` |
| `ffmpeg` | 载入音频失败，或转换出来的文件是空的 |
| GPU | 不是必须，但 CPU 跑一首歌要等很久 |

环境装完回页面点一次「重新检查」，别看着旧状态猜。

## 音色从哪来

| 来源 | 做法 | 注意 |
| --- | --- | --- |
| 别人的现成模型 | 下载 `.pth` + `.index` 放进音色目录 | 只放你确定有授权的 |
| 自己录 | 一段几十秒到几分钟的干净人声，按页面提示训练 | 训练要时间，CPU 上很慢 |

干声的要求很朴素：**只有人声，没有伴奏、没有混响、没有削波**。手机在衣柜里录都比在客厅录好。

## 怎么用

| 场景 | 操作 |
| --- | --- |
| 让她唱一首 | 直接说「唱一首 xxx」，走内置唱歌流程，出稿后用选中的音色变声 |
| 点歌后选翻唱 | 见[点歌](/features/music)，明确要求翻唱时才走这条路 |
| 语音条变声 | 什么都不用做：翻唱音色选过且环境就绪，语音条自动变声 |

## 失败一律降级，不会整条挂掉

翻唱没就绪时，语音条**退回原声**照常发出，不报错。所以「怎么没变声」通常在日志里，不在报错里：

```text
翻唱模块没就绪，这一轮没变声（原声）
翻唱里没有音色「X」，这一轮没变声（原声）
变声失败，用原声：<具体报错>
```

看见这三行里的任意一行，就按字面意思去修。

## 排错

| 现象 | 原因 |
| --- | --- |
| 环境检查一直红 | Python 没进 PATH，或装的是 Microsoft Store 的假 Python |
| 转换卡住不动 | CPU 跑大模型，等；或音色 `.index` 文件缺失 |
| 出来是杂音 / 电流声 | 干声太差，或音高设置不对，先换一个音色试 |
| 唱歌正常、语音条不变声 | 语音条走的是 TTS 再变声，先确认 TTS 那条通 |
| 换了音色没变化 | 没保存，或者语音条那一条是缓存的旧音频 |
