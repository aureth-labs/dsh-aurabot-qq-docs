# 功能总览

这一组页面讲**配好之后怎么用、配错了怎么查**。前置条件都一样：DSH 跑起来、模型能用、AuraBot 装好、机器人号在线。

还没到这一步的话，先走[入门](/guide/install)。

## 分三组看

### 聊天这一侧

| 功能 | 一句话 | 页面 |
| --- | --- | --- |
| 人格 & 心情 | 她是谁、此刻什么情绪，决定她怎么说话 | [人格、心情与群聊](/features/chat) |
| 群聊策略 | 被叫必回、正在参与就接话、其余偶尔插一句 | [人格、心情与群聊](/features/chat) |
| 记忆 | 本地记忆库 + 人物档案 + 相处经验 + 说话方式 | [记忆](/features/memory) |
| 表情包 | 自己收、自己起名、按语境挑 | [表情包](/features/sticker) |

### 说和唱

| 功能 | 一句话 | 额外要准备 | 难在哪 |
| --- | --- | --- | --- |
| [语音](/features/voice) | 把回复念成语音条 | `edge-tts` | Python 环境 |
| [TTS：换一个嗓子](/features/tts) | 内置音色不好听，换豆包 / 千问 / 自己的接口 | 平台密钥或接口 | 资源 ID 填错 |
| [翻唱](/features/cover) | 用你的音色唱歌 | Windows + RVC + 音色模型 | 环境与音色导入 |

## 都放在面板哪一页

| 面板分组 | 页面 | 管什么 |
| --- | --- | --- |
| 概览 | 状态、日志、日志级别 | 总开关、试运行、看日志 |
| 说话 | 连接、人格、权限、群聊、模型、语音、表情包、画图、心情与记忆、人物记忆 | 她怎么说话、能做什么 |
| 生活 | QQ 空间、B 站、翻唱、主动搭话、桌宠、模块市场 | 对外的社交动作 |

## 通用排查顺序

功能不对，先按这个顺序排，九成问题在前两步：

```text
1. 模块装了吗、启用了吗        → 模块市场 → 已安装
2. 面板对应页的开关打开了吗    → 画图 / 语音 / 翻唱 各自的页
3. 权限放开了吗                → 权限页：画图、点歌默认要求「都是主人」
4. 依赖装了吗                  → edge-tts、ffmpeg、RVC、Python
5. 外网通吗                    → 日志里看请求是不是超时 / 401
```

某个功能的标签页整页不见了，先去「已安装」页看对应模块是不是被关了。

## 别把这些当成一回事

| 容易误解 | 实际是什么 |
| --- | --- |
| 「语音」页就是 TTS | 语音页管**要不要发语音条**；用哪个引擎是 TTS 的事 |
| 翻唱能替代语音 | 翻唱只做变声，念稿还是 TTS 的事 |
| 装了生图模块就自动画 | 必须**自己选一个模型**，不选就走内置那三条 |
| 点歌等于翻唱 | 点歌发的是原唱；翻唱是另一条路 |
| 主动搭话和目的引擎能一起开 | 会重复打扰，只能开一套 |
