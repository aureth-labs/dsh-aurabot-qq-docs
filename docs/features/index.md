# 功能总览

这一组页面只讲**配好之后怎么用、配错了怎么查**。前置条件都一样：
DSH 跑起来、模型能用、AuraBot 装好、机器人号在线。

还没到这一步的话，先走[入门](/guide/install)。

## 五件事，五套准备

| 功能 | 一句话 | 额外要准备什么 | 难在哪 |
| --- | --- | --- | --- |
| [画图](/features/image) | 让她发图，不是描述图 | 一个生图模型 | 模型清单是空的 |
| [语音](/features/voice) | 把回复念成语音条 | `edge-tts` | Python 环境 |
| [TTS：换一个嗓子](/features/tts) | 内置音色不好听，换豆包 / 千问 | 平台密钥 + 音色 ID | 资源 ID 填错 |
| [翻唱](/features/cover) | 用你的音色唱歌 | Windows + RVC + 音色模型 | 环境与音色导入 |
| [点歌](/features/music) | 直接甩一条歌过来 | 搜索通道 | 平台限流、VIP 曲 |

## 都放在面板哪一页

| 面板分组 | 页面 | 管什么 |
| --- | --- | --- |
| 说话 | 画图 | 风格描述、内置生图接口、是否用 DSH 已接入的模型 |
| 说话 | 语音 | 语音开关、音色、试听、`edge-tts` 安装、语音识别自检 |
| 生活 | 翻唱 | RVC 环境、音色导入、选中的音色 |
| 生活 | 模块市场 | 装上面这些功能对应的社区模块 |

## 一个通用的判断顺序

功能不对，先按这个顺序排，九成问题在前两步：

```text
1. 模块装了吗、启用了吗        → 模块市场 → 已安装
2. 面板对应页的开关打开了吗    → 画图 / 语音 / 翻唱 各自的页
3. 权限放开了吗                → 权限页：画图、点歌默认要求「都是主人」
4. 依赖装了吗                  → edge-tts、ffmpeg、RVC、Python
5. 外网通吗                    → 面板日志里看请求是不是超时 / 401
```

## 别把这些当成功能

| 容易误解 | 实际是什么 |
| --- | --- |
| 「语音」页就是 TTS | 语音页管的是**要不要发语音条**；具体用哪个引擎由 TTS 决定 |
| 翻唱能替代语音 | 翻唱只做变声，念稿还是 TTS 的事 |
| 装了生图模块就自动画 | 必须**自己选一个模型**，不选就走内置那三条 |
| 点歌等于翻唱 | 点歌发的是原唱；翻唱是另一条路 |
