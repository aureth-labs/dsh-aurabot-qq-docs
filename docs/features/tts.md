# TTS：换一个嗓子

内置语音用的是 `edge-tts`，免费但不贴人设。想换嗓子就装一个 TTS 模块，**它会顶替内置语音**：
聊天中枢要发语音条时调模块的 `speak(text)`，不再走 `edge-tts`。

语音开关还在「语音」页，只是引擎换了。见[语音](/features/voice)。

## 现在能选的两个

| 模块 | 平台 | 要准备的东西 | 特点 |
| --- | --- | --- | --- |
| `voice`（豆包语音 2.0） | 火山引擎 | API Key、资源 ID、音色 Speaker ID | 支持声音复刻、指令式情绪 |
| `qwen-tts`（千问百炼） | 阿里云百炼 | 百炼 API Key、模型、音色 | 支持语速、自然语言语气、长文本分段 |

两个都是 MIT，都只把合成请求发给各自平台，密钥只存本机配置。

## 通用步骤

不管装哪个，顺序一样：

1. 面板「模块市场」搜 `语音` / `豆包` / `千问`，装
2. 启用
3. 回「说话 → 语音」页，底部会多出这个模块自己的设置区
4. 填密钥 + 音色，点「试听」
5. 试听通了再回 QQ 里试一条

::: tip 两条通道不一样
「试听」走的是模块自己合成的音频，直接播在浏览器里；QQ 里的语音条还要经过上传和发送。
试听通、QQ 不通，问题在发送环节。
:::

## 豆包语音 2.0 的坑

| 字段 | 填错会怎样 |
| --- | --- |
| 资源 ID | 复刻音色用 `seed-icl-2.0`，预置 2.0 音色用 `seed-tts-2.0`；用错报 `55000000` |
| 音色 Speaker | 复刻音色是 `S_` 开头的 ID；预置 2.0 音色以 `_uranus_bigtts` 结尾 |
| 语速 | 默认 `0`，觉得快就调到 `-10` 到 `-20`，**下一条**语音才生效 |
| 固定语气指令 | 一行一条，例如「用温柔、放慢一点的语气说这句话」；留空就不加 |

另外一个开关是「按文字自动配语气」：按回复里的关键词自动追加语气指令（开心 / 难过 / 撒娇 / 安慰），不额外计费。

## 千问百炼的坑

1. 先在「语音」页点「安装脚本」，生成 `local/tts.mjs`
   ——**已经有这个文件就不会覆盖**，想换版本要先手动备份、移走
2. 在「本地接口」页开启语音
3. 回模块面板填百炼 API Key、模型、音色，保存，试听
4. `ffmpeg` 可选，找不到就保留原始音频

设置存在 `local/tts.config.json`，合成音频与缓存在 `local/` 下。

## 合成失败会怎样

不会让她突然哑掉：模块合成失败时自动退回内置 `edge-tts` / Windows 本机语音，这一条照常发出去，只是声音变回内置音色。

所以排查时先看面板日志有没有「已回退」的字样——有就说明是模块那条路挂了，不是语音页的问题。

## 回滚到内置

| 想干什么 | 怎么做 |
| --- | --- |
| 临时用回内置 | 面板「已安装」给 `voice` / `qwen-tts` 那一行打开「用内置的」 |
| 彻底移除 | 删掉模块文件夹，或市场里卸载 |

## 计费提醒

试听和正式合成都产生请求，都可能计费。部分模型和地域有限时免费额度，
额度和有效期以各平台说明为准，别按「免费」来规划用量。
