# TTS：换一个嗓子

内置 `edge-tts` 免费但不贴人设。想换嗓子有两条路：**装成品模块**，或者**自己接一个 HTTP 接口**。

## 路线一：成品模块

| 模块 | 平台 | 要准备 | 特点 |
| --- | --- | --- | --- |
| `voice`（豆包语音 2.0） | 火山引擎 | API Key、资源 ID、音色 Speaker ID | 声音复刻、指令式情绪 |
| `qwen-tts`（千问百炼） | 阿里云百炼 | 百炼 API Key、模型、音色 | 语速、自然语言语气、长文本分段 |

两个都 `replacesBuiltin: true`：装上就顶替内置语音，聊天中枢要发语音条时调模块的 `speak(text)`。

通用步骤：

1. 面板「模块市场」搜 `语音` / `豆包` / `千问`，装
2. 启用
3. 回「说话 → 语音」页，底部会多出这个模块自己的设置区
4. 填密钥 + 音色，试听
5. 试听通了再回 QQ 里试一条

## 路线二：自己接 HTTP 接口

「语音」页的「其他 HTTP 接口」：

| 字段 | 说明 |
| --- | --- |
| 地址 | 完整 URL |
| 请求方式 | `GET` / `POST` |
| 请求头 | 一行一个，放鉴权用 |
| 请求体 | `{text}` 会自动转义，`{reqid}` 每次换新 |

返回 JSON（base64）会自动解成音频。所以火山、阿里、讯飞这些要签名鉴权的云 TTS 也能直接接，不用写模块。

## 豆包语音 2.0 的坑

| 字段 | 填错会怎样 |
| --- | --- |
| 资源 ID | 复刻音色用 `seed-icl-2.0`，预置 2.0 音色用 `seed-tts-2.0`；用错报 `55000000` |
| 音色 Speaker | 复刻音色是 `S_` 开头的 ID；预置 2.0 音色以 `_uranus_bigtts` 结尾 |
| 语速 | 默认 `0`，觉得快调到 `-10` 到 `-20`，**下一条**才生效 |
| 固定语气指令 | 一行一条，如「用温柔、放慢一点的语气说这句话」；留空不加 |

另有「按文字自动配语气」：按回复里的关键词自动追加语气指令（开心 / 难过 / 撒娇 / 安慰），不额外计费。

## 千问百炼的坑

1. 先在「语音」页点「安装脚本」，生成 `local/tts.mjs`
   ——**已经有这个文件就不会覆盖**，换版本要先手动备份、移走
2. 在「本地接口」页开启语音
3. 回模块面板填百炼 API Key、模型、音色，保存，试听
4. `ffmpeg` 可选，找不到就保留原始音频

设置存 `local/tts.config.json`，合成音频与缓存在 `local/` 下。

## 失败不会让她哑掉

模块合成失败时自动退回内置 `edge-tts` / Windows 本机语音，这一条照常发出去，只是变回内置音色。所以排查时先看日志有没有「已回退」——有就说明是模块那条路挂了。

## 回滚

| 想干什么 | 怎么做 |
| --- | --- |
| 临时用回内置 | 面板「已安装」给那一行打开「用内置的」 |
| 彻底移除 | 市场里卸载，或删模块文件夹 |

## 计费

试听和正式合成都产生请求，都可能计费。部分模型和地域有限时免费额度，额度和有效期以各平台说明为准，别按「免费」规划用量。
