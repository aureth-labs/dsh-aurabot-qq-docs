# 语音合成

语音合成负责将文字转换为音频。可以安装社区模块，也可以使用自定义 HTTP 接口。

## 社区模块

| 模块 | 服务 | 必要配置 |
| --- | --- | --- |
| `voice` | 火山引擎豆包语音 2.0 | API Key、资源 ID、音色 Speaker ID |
| `qwen-tts` | 阿里云百炼 | 百炼 API Key、模型和音色 |

这些模块使用 `replacesBuiltin: true`，启用后接管内置语音合成。

安装后在「语音」页面填写模块配置并试听。试听成功后再测试平台发送。

## 自定义 HTTP 接口

| 字段 | 内容 |
| --- | --- |
| 地址 | 完整接口 URL |
| 请求方式 | `GET` 或 `POST` |
| 请求头 | 每行一项，可包含鉴权信息 |
| 请求体 | 支持 `{text}` 和 `{reqid}` 占位符 |

接口可返回音频或包含 Base64 音频的 JSON。具体鉴权方式由服务方决定。

## 豆包语音配置

| 配置 | 说明 |
| --- | --- |
| 资源 ID | 复刻音色使用 `seed-icl-2.0`，预置 2.0 音色使用 `seed-tts-2.0` |
| Speaker ID | 与音色类型匹配 |
| 语速 | 默认 `0`，可按需调整 |
| 固定语气指令 | 每行一条，留空表示不添加 |

资源 ID 与音色类型不匹配时可能返回 `55000000`。配置修改从下一条合成开始生效。

## 千问百炼配置

先生成 `local/tts.mjs`，再启用本地语音接口并填写百炼 API Key、模型和音色。已有脚本不会被自动覆盖。

配置保存在 `local/tts.config.json`，合成文件和缓存位于 `local/`。FFmpeg 可选。

## 失败与回退

社区模块合成失败时，可回退到内置 `edge-tts` 或 Windows 系统语音。日志会记录回退原因。

临时恢复内置语音时，在「已安装」中启用「用内置的」；彻底移除时卸载对应模块。

试听和正式合成都可能产生服务费用，额度以提供商说明为准。
