# 点歌

让她把一首歌**以语音条的形式**发到当前会话。点歌只发**原唱**，不做翻唱、不做变声——想听她唱，走[翻唱](/features/cover)。

## 两条路

| 路子 | 谁在干 | 特点 |
| --- | --- | --- |
| 内置点歌（`song`） | AuraBot 自带 | 装了就能用，能力有限 |
| 社区模块 `shangxue-playmusic`（语音点歌） | 哔哩哔哩 + 网易云 | 搜原唱、按匹配度挑一条、抽成 mp3 发语音条；**不需要任何 Cookie** |

要稳定点歌，直接用模块。

## 装语音点歌

1. 面板「模块市场」搜 `点歌`，装 `shangxue-playmusic`
2. 确认本机有 **`ffmpeg`**：`PLAYMUSIC_FFMPEG` / `AURABOT_FFMPEG` 环境变量、常见盘符路径、`PATH` 三者任一命中即可
3. 面板里按需调配置，然后试一句「点歌 晴天」

`ffmpeg` 没找到时模块会明确报错，不会静默失败。它的 `/status` 路由里能看到 `ffmpegOk`。

## 它能做什么

| 工具 / 指令 | 干什么 |
| --- | --- |
| `shangxue_playmusic_search` | 按歌名搜候选，只搜不下载。每平台 5 条，两个平台合计最多 10 条，返回 Markdown 表格 |
| `shangxue_playmusic_sendsong` | 按 `platform`（`bilibili` / `netease`）+ `id`（BV 号 / 歌曲 id）下载、抽音、发语音条 |
| `/music <歌名>` | 独立指令入口，**不吃算力、不经 AI**默认开着，指令名可在面板改 |

流程是：你说点歌 → 主模型调 `search` → 挑最像原唱的一条 → 调 `sendsong`。
你直接甩一个 BV 号或歌曲 id，它会跳过搜索。`sendsong` 的 `id` 传整条 B 站链接也能用，会自动抠出 `BVxxxxxxxxxx`。

## 为什么不需要 Cookie

- 哔哩：走**星之阁**第三方接口，不碰你自己的账号
- 网易云：公开搜索接口 + Meting 直链，只取免费能拿到的音源

搜索本身是**四路并行**：哔哩直连 / 哔哩代理 / 网易云直连 / 网易云代理同时发出，每个平台取最快的一条**有效**结果。空响应、空列表都算失败，会换下一路。

## 配置项

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 总开关 | 开 | 关掉后不再提供点歌工具 |
| 搜索来源 | 哔哩+网易云 | 也可以只留一个平台 |
| 语音条最长时长 | 10 分钟 | 范围 4 到 30 分钟，超出截断 |
| 代理地址 | 空 | 留空用内置 apifox；填 `direct` 只直连；填其它地址用自定义代理 |
| 仅主人可用 | 关 | 打开后只有主人能点 |
| 注册点歌指令 | 开 | 关掉就只剩 AI 工具，只能靠说话触发 |
| 点歌指令名 | `music` | 不带斜杠 |
| 给 AI 的提示词 | 见默认值 | 支持 `{{source}}`、`{{searchTool}}`、`{{sendTool}}`、`{{perLimit}}` |

## 曲库查询是另一件事

`music-discovery` 不下载、不发语音条，只管**查**：搜歌、推荐、排行榜、歌单、听歌报告、AI 解读。
想让她「知道」这首歌是什么，用它；想让她「发出来」，用点歌。

它明确不调用翻唱模块——你要求翻唱时，交回你原本的翻唱功能。

## 排错

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 搜到但发不出来 | 没有 `ffmpeg` | 装 `ffmpeg` 或设 `PLAYMUSIC_FFMPEG` |
| 搜出来一堆翻唱版 | 「原唱」判断靠标题与时长，B 站本来就杂 | 直接给 BV 号最准 |
| 两个平台都搜不到 | 代理挂了 / 平台限流 | 代理填 `direct` 再试一次；或只留一个来源 |
| 语音条只有前 10 分钟 | 默认截断 | 面板把「语音条最长时长」调大 |
| 指令 `/music` 没反应 | 指令注册关了，或指令名改过 | 面板看「注册点歌指令」和「点歌指令名」 |
| 群里有别人点时失败 | 「仅主人可用」开着 | 关掉，或让主人来点 |

## 版权与频率

点歌会把整首歌的音频发到会话里。私人群里自己听没人管，**公开发**就是在传播录音制品。
另外别在群里连着点十几首——平台会限流，机器人号也不安全。
