# 点歌

点歌功能搜索歌曲、获取音源并发送原唱语音。音色转换由[翻唱](/features/cover)单独处理。

## 实现方式

| 方式 | 说明 |
| --- | --- |
| 内置 `song` 模块 | 提供基础点歌能力 |
| 社区模块 `shangxue-playmusic` | 使用哔哩哔哩和网易云搜索，处理音频并发送语音 |

社区模块的搜索和公开音源流程不要求用户 Cookie。

## 安装语音点歌

1. 在模块市场安装 `shangxue-playmusic`。
2. 安装 FFmpeg，或配置 `PLAYMUSIC_FFMPEG`、`AURABOT_FFMPEG`。
3. 保存模块配置并测试「点歌 晴天」。

`/status` 路由中的 `ffmpegOk` 可用于检查 FFmpeg 状态。

## 工具与指令

| 名称 | 作用 |
| --- | --- |
| `shangxue_playmusic_search` | 搜索候选歌曲，每个平台最多返回 5 条 |
| `shangxue_playmusic_sendsong` | 按平台和歌曲 ID 下载、转换并发送 |
| `/music <歌名>` | 直接执行点歌指令 |

模型通常先调用搜索工具，再选择候选并调用发送工具。提供 BV 号、网易云歌曲 ID 或受支持的链接时，可以跳过搜索。

搜索使用直连与代理并行请求，每个平台采用最先返回的有效结果。空响应和空列表不视为成功。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 总开关 | 开 | 控制点歌工具注册 |
| 搜索来源 | 哔哩哔哩和网易云 | 可只保留一个来源 |
| 语音条最长时长 | 10 分钟 | 可设为 4 到 30 分钟 |
| 代理地址 | 空 | 空值使用内置代理，`direct` 表示仅直连 |
| 仅主人可用 | 关 | 限制可点歌的用户 |
| 注册点歌指令 | 开 | 关闭后只保留模型工具 |
| 点歌指令名 | `music` | 不包含斜杠 |

## 曲库查询

`music-discovery` 用于搜索、推荐、排行榜、歌单和歌曲信息查询，不下载或发送音频，也不代替翻唱功能。

## 排查

| 现象 | 检查项 |
| --- | --- |
| 搜索成功但无法发送 | FFmpeg 路径和音频处理日志 |
| 搜索结果多为非原唱 | 改用明确 BV 号或歌曲 ID |
| 两个来源都失败 | 网络、代理和平台限流 |
| 音频被截断 | 语音条最长时长 |
| `/music` 无响应 | 指令注册开关和自定义指令名 |
| 非主人无法点歌 | 「仅主人可用」配置 |

发送完整歌曲涉及录音制品的使用与传播。公开分享和高频请求应分别考虑版权与平台限制。
