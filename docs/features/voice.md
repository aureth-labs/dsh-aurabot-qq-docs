# 语音

「语音」这一页管的是**要不要发语音条**，不是「用哪个引擎」。引擎的事在 [TTS](/features/tts)。

默认实现是 `edge-tts`（微软在线朗读，免费、要联网），失败会退到 Windows 本机语音；Linux / macOS 上没有本机语音兜底。

## 打开语音

1. 装 `edge-tts`：

   ```bash
   pip install edge-tts
   ```

   装不了就先看 Python 在不在 PATH 里。面板「语音」页上有「安装 edge-tts」按钮，它会调同样的东西，输出会打在面板日志里。

2. 面板「说话 → 语音」→ 打开语音
3. 选一个音色，点「试听」
4. 保存

试听能出声就通了。**试听不经过 QQ**，所以试听行、语音条不行的，问题在发送环节，不在合成。

## 她会什么时候发语音

| 情况 | 行为 |
| --- | --- |
| 语音开关关着 | 只发文字，永远不发语音条 |
| 语音开着 | 由她的回复内容决定要不要念出来（调情、撒娇、想说长句时更容易触发） |
| 你明确要求「说给我听」 | 会念 |

不是每条消息都转语音——那样又吵又费额度。想强制每条都念，得自己在人格或指令里要求。

## 音色怎么来

内置音色来自 `edge-tts` 的音色表，中文常用的是 `zh-CN-XiaoxiaoNeural` 这一类。
在面板下拉框里能看到的都能用，试听逐个听一遍比看名字快。

想要更贴人设的嗓子，看 [TTS：换一个嗓子](/features/tts)。

## 翻唱音色会盖到语音条上

如果「生活 → 翻唱」里已经选了一个音色并且环境就绪，语音条会先合成再用 RVC 变一次声——**说话和唱歌是同一个声音**。

翻唱没就绪时不会失败，只是这一轮不变声（原声发出）。面板日志里会写明「翻唱模块没就绪，这一轮没变声」这类原因。

## 语音识别（她听你说话）

「语音」页上有语音识别自检。桌宠模块的对讲、语音通话都依赖它：

| 用途 | 走哪 |
| --- | --- |
| QQ 里发语音消息给她 | 语音识别（ASR）→ 文字 → 正常回复 |
| 桌宠对讲 | 面板里的 `talk` 接口，一轮「识别 → 思考 → 合成」 |
| 语音通话 | 社区模块 `voicecall` |

ASR 没就绪时，发语音给她只会被当成一条空消息。自检里会给出原因。

## 排错

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 试听没声音 | `edge-tts` 没装好，或没联网 | 命令行跑一次 `edge-tts --list-voices` 看报什么 |
| 试听行、QQ 里不发 | 语音开关没开，或权限没过 | 面板「语音」+「权限」各看一眼 |
| 声音是机器人腔 | 用的内置音色 | 换音色，或上 [TTS](/features/tts) |
| 一句话念到一半断 | 文本太长被平台切了 | 调小单条上限，或让她说短点 |
| 每句都变声失败 | 翻唱音色选过但环境没就绪 | 「翻唱」页看环境状态，或先不选音色 |
