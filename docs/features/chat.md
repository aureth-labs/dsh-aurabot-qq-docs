# 聊天：人格、心情与群聊

她怎么说话由三样东西决定：**人格**（她是谁）、**心情**（她此刻的情绪）、**群聊策略**（这个场合该不该开口）。
三样都在面板里，改完下一轮就生效，不用重启。

## 人格

面板「说话 → 人格」：

| 操作 | 说明 |
| --- | --- |
| 直接改文字 | 保存后从下一句话起生效 |
| 切换人格卡 | 选中一张，点「设为当前」 |
| 按节编辑 | 人格文件分成若干节，可以只改其中一节 |

人格放在系统提示词最前面，所以它压得住别的规则。改坏了不用怕——面板「系统 → 备份」里有旧版本。

## 心情

心情是 0 到 1 的几个维度，被夸、被凶、被冷落都会推动它，然后按半衰期慢慢回到平常。

| 心情明显时 | 实际影响 |
| --- | --- |
| 语气 | 每轮会告诉她「现在该怎么说话」 |
| 发表情的概率 | 高心情更容易发表情 |
| 发语音的概率 | 同上 |
| 回复快慢 | 低落时回得慢 |
| 插话积极程度 | 高兴时更愿意插一句 |

判定方式有两种：默认按关键词，也可以在「心情与记忆」页改成**每轮用模型判一次**（更准，但每轮多一次模型调用）。

## 群聊怎么决定回不回

群里不是每条都回。她按这个顺序判断：

```text
被 @ / 被引用 / 被叫名字        → 必回
正在参与这个话题（上下文连续）  → 接着聊
话题相关度高                    → 可能插一句
都不满足                        → 不说话
```

面板「说话 → 群聊」能调「插话概率」，也可以只对某个群单独设。另有防刷屏的刹车：一段时间内说得太多会自己停。

群里停顿几秒算一段。她回上一段时，新消息先攒着，看完整段再回——**不会一条一回**。交给她的是这一段谁说了什么、之前在聊什么；新消息带编号，想专门接某一条时可以引用回复。

## 引用、@ 和合并转发

| 场景 | 她的行为 |
| --- | --- |
| 别人引用一条消息 | 会去查被引用的内容（谁说的、正文、图/表情），私聊群聊都能看到；引用的是她自己说的话时标成「你」 |
| 引用查不到 | 会知道「这条引用没读到」，如实说没看到，不装作看见 |
| 她 @ 人 | 只认**群名片和 QQ 昵称**。对不上、或者群里有同名，就不 @，只把名字当普通文字发 |
| 合并转发 | 展开成里面的聊天记录再读 |
| 被拍一拍 | 当成对她说话，偶尔拍回去 |

::: warning 手机上的备注她看不到
你给好友设的备注她读不到。你备注「小明」、他在群里叫「Luna」，你说「去 @小明」她是找不到的——给群名片或 QQ 号。
:::

## 替你去别的群说话

在和她私聊时说：

```text
去 123456789 群说一声今晚八点开会
跟 10001 私聊说我晚点回
```

对方必须在白名单里。说完她会记住自己在那里说过什么，那个群下次有人找她时能接上。

## 让她读群里的情况

面板「说话 → 群聊」里有个默认关闭的开关：**主人私聊问「群里刚才在聊什么」**。

打开后，她只在你私聊、且这句话和群相关时，把最近 24 小时白名单群的聊天流水当成「自己看到的见闻」接着说。不常驻上下文、不写进记忆。可以限定只取哪些群、每群给几条（最多 30 条）。

## 发文件

私聊里说「把 xx 文件发给我」就行，也能发给白名单里的人或群。

| 限制 | 值 |
| --- | --- |
| 能发哪里 | 只发 QQ 工作区，和你在「聊天」页额外加的目录 |
| 单个文件 | 默认最大 50 MB |
| 记录 | 每次发了什么都会写进日志 |

在「聊天」页可以整个关掉。

## 危险命令确认（可选，默认关）

打开后，她在私聊里要执行删除根目录、格式化、关机、下载后直接执行这类终端命令之前，会先私聊问你：回「确认」才执行，回「取消」或 60 秒没回就拦下，并且会把要执行的命令原文给你看。

群聊和其他人的会话**没有本地终端工具**，碰不到这个开关。

## 隐私边界

| 边界 | 规则 |
| --- | --- |
| 主人私聊的内容 | 不会被带进群聊或别人的私聊 |
| 记忆 | 按聊天来源隔离 |
| 社交场景 | 只回忆当前聊天里的事 |
