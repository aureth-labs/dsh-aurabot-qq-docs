# 人格、心情与群聊

人格定义表达风格，心情影响当前状态，群聊策略决定是否回复。这些配置通常在下一轮处理时生效。

## 人格

在「说话 → 人格」中可以编辑当前人格、切换人格卡或按章节修改内容。人格文本位于系统提示词前部。

修改前建议先使用「系统 → 备份」保存当前数据，以便恢复。

## 心情

心情由多个取值范围为 0 到 1 的维度组成。对话事件会改变状态，随后按半衰期逐渐回到基准值。

心情可影响：

- 回复措辞和生成速度；
- 发送表情或语音的概率；
- 群聊主动插话的程度。

默认使用关键词判断，也可以配置为每轮调用模型判断。后者会增加模型请求。

## 群聊回复

当前策略按以下信息判断：

```text
被 @、被引用或被叫名字 → 回复
正在参与当前话题       → 可继续回复
与话题相关             → 按概率插话
其他消息               → 通常不回复
```

「说话 → 群聊」可调整插话概率，并为单个群设置不同策略。频率限制用于避免连续刷屏。

短时间内的一组消息会作为一个片段处理。模型生成上一段回复时，新消息会暂存，再连同后续上下文一起处理。

## 引用与转发

| 输入 | 处理方式 |
| --- | --- |
| 引用消息 | 尝试读取被引用内容；读取失败时明确说明 |
| @ 用户 | 根据群名片或 QQ 昵称匹配；无法唯一匹配时不添加 @ |
| 合并转发 | OneBot v11 在当前适配器实例开启「展开合并转发」时，会读取其中的文字和图片。默认开启，关闭后保留转发引用。 |
| 拍一拍 | 作为交互事件处理 |

手机联系人备注不会同步给机器人。需要指定用户时，使用群名片或 QQ 号。

## 跨聊天发送

在主人私聊中可以请求向白名单内的群或用户发送消息，例如：

```text
去 123456789 群说一声今晚八点开会
跟 10001 私聊说我晚点回
```

发送记录会进入相应会话，供后续对话使用。

## 文件与命令权限

文件发送仅限配置允许的目录，默认单文件上限为 50 MB，并记录发送日志。

可选的危险命令确认功能会在执行高风险终端命令前请求主人确认。群聊和其他用户的私聊默认不提供本机终端工具。

## 数据隔离

主人私聊内容不会直接带入群聊或其他用户私聊。记忆按来源隔离，检索时只使用当前社交场景允许的数据。
