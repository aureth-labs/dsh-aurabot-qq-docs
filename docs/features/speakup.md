# 主动搭话

她只会在**和你的私聊**里主动开口，群里不会。你一阵子没理她，她会来找你；她问了你一句你很久没回，偶尔会轻轻追一句。

面板「生活 → 主动搭话」，「概览」页也有一个「现在就让她来找我」的按钮。

## 两套引擎，只能开一套

| 引擎 | 状态 | 怎么决定说什么 |
| --- | --- | --- |
| 主动搭话（默认） | 一直在，主路径 | 按「多久没说话」「上次聊到哪」这类简单规则 |
| 目的引擎（`purpose`） | 实验性，**默认关** | 先攒素材，再猜「她现在想要什么」，挑一个目标，生成一句话，投到主人私聊 |

::: danger 别同时开
两套同时开会**重复打扰**你。想换引擎：打开目的引擎，同时关掉主动搭话的总开关。
:::

作息是同一份：目的引擎沿用主动搭话的醒着时段（`awakeFrom` / `awakeTo`），所以你不会遇到「一个引擎睡了另一个还在说话」。

## 常用设置

| 设置 | 作用 |
| --- | --- |
| 醒着时间 | 只在这个区间里主动说话；设成全天等于关掉安静时段 |
| 间隔 | 最短 / 最长间隔，到点才可能开口 |
| 每天上限 | 一天最多主动几次 |
| 多久没理她才算「冷落」 | 太短会烦，太长她就不找你了 |
| 白名单 | 只在主人私聊，不存在群白名单这回事 |

## 目的引擎在干什么

```text
素材（最近 2 天聊天流水 + 记忆 + 当前人格 + 上一轮的待续事项）
   └─ 目标假设：归属（自己 / 主人 / 群友 / 媒体）、置信度、风险、紧急度
        └─ 选一个目的（9 个维度里挑）
             └─ 生成一句话
                  └─ 投递到主人私聊
```

9 个维度是：玩、学、装、陪、关心、分享、自我、创作、体验。它们会随时间衰减（半衰 8 小时），主人沉默越久「陪」越高，说完一次对应维度会掉到 45%。

生成失败或判定「现在不该说」的时候，她会**沉默**，不会硬发一条凑数。

## 投递到哪

默认投到 QQ 私聊。也可以改成走桌宠气泡：

| 载体 | 行为 |
| --- | --- |
| `qq`（默认） | 发 QQ 私聊 |
| `pet` | 推桌面气泡；桌宠没开时按设置回落 QQ 或静默 |

一轮只发一处，不会两边都弹。

## 排查

| 现象 | 原因 |
| --- | --- |
| 她从来不主动 | 主动搭话总开关关着；或者不在醒着时段；或者每天上限已经用完 |
| 一天来好几次 | 间隔设太短，或者目的引擎和主动搭话同时开着 |
| 目的引擎开了没反应 | 素材不够（默认要攒一定条数）；或者刚启动还在等首次延迟 |
| 想说的时候全是「在吗」 | 素材太少，多聊几天；或把 `promptMaxChars` 调大，让她能多说点 |
| 重启后有一条「待续」没了 | 在途的待续事项在重启时判为「被打断」，不补发 |
