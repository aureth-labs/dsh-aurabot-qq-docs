# 主动搭话

主动搭话只向主人私聊发送消息，不在群聊中主动发言。配置位于「生活 → 主动搭话」。

## 两套实现

| 实现 | 状态 | 决策方式 |
| --- | --- | --- |
| 主动搭话 | 默认实现 | 根据沉默时间、上次对话和频率规则 |
| 目的引擎 `purpose` | 实验性，默认关闭 | 综合素材、目标候选和状态生成消息 |

不要同时启用两套实现，以免重复发送。作息时段共用 `awakeFrom` 和 `awakeTo` 配置。

## 常用配置

| 配置 | 作用 |
| --- | --- |
| 醒着时间 | 限定允许主动发送的时段 |
| 间隔 | 设置最短和最长发送间隔 |
| 每天上限 | 限制每日主动消息数量 |
| 冷落判定时间 | 决定多久未回复后触发追问 |

## 目的引擎

目的引擎读取最近两天的聊天流水、记忆、当前人格和待续事项，生成目标候选，再决定是否发送。

目标维度包括玩、学、装、陪、关心、分享、自我、创作和体验。权重随时间衰减，并在发送后调整。

生成失败或判断当前不适合发送时，本轮保持沉默。

## 发送位置

| 配置 | 行为 |
| --- | --- |
| `qq` | 发送 QQ 私聊 |
| `pet` | 发送桌宠气泡；桌宠不可用时按配置回退 |

每轮只选择一个发送位置。

## 排查

| 现象 | 检查项 |
| --- | --- |
| 从不主动发送 | 总开关、时段和每日上限 |
| 发送过于频繁 | 时间间隔，以及是否同时启用两套实现 |
| 目的引擎没有输出 | 素材数量和首次延迟 |
| 内容重复或空泛 | 可用素材和 `promptMaxChars` |
| 重启后待续事项消失 | 在途事项会在重启时标记为中断，不自动补发 |
