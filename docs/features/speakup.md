# 主动搭话

AuraBot 的目的引擎根据当前人格、近期聊天和记忆，决定何时主动联系主人。它默认启用。先在面板接入机器人，登记该平台的主人 ID，并等待适配器上线。一个平台接入多个机器人时，为主人指定机器人实例。

## 发送到哪一个私聊

自动调度每次最多联系一人。开放平台按平台、机器人实例、登录账号、接收人和人格分开保存搭话状态。生成期间如果主人发来新消息、切换人格、取消授权或机器人重新登录，引擎会放弃旧草稿。

在「主动搭话」页可以选一个在线的主人账号，预览话题或手动触发。预览只读取素材。手动触发可以跳过作息排程，模型仍可以选择沉默。投递得到确认后，下次对话就能看到这次发言。主 QQ 账号另支持白名单朋友和桌宠气泡，桌宠离线时可配置是否回落到 QQ 私聊。

## 作息与提醒

| 设置 | 对自动搭话的影响 |
| --- | --- |
| 醒着时间 | 控制允许联系的时段，支持跨午夜 |
| 空闲时间 | 决定上次私聊多久后才能开口 |
| 发送间隔 | 在最短与最长间隔之间安排下一次机会 |
| 每天上限 | 每个目标单独累计 |
| 小闹钟 | 允许模型根据主人在私聊中的约定，设置、查看和关闭一次性提醒 |

小闹钟默认关闭。在主人私聊里开启后，模型可以使用 `purpose_set_reminder`、`purpose_list_reminders` 和 `purpose_close_reminder`。时间采用机器人主机的本地时间。闹钟到点后优先于普通排程，模型会重新决定是否适合打扰。面板可以取消尚待投递的提醒。

较早的 V2 测试版没有在会话数据库里记录适配器的登录账号。升级后，同一平台和实例首次上线的账号承接该实例原有的会话记录；此后切换账号会使用独立的记录。旧版 QQ 闹钟没有主人字段，升级时由首次读取它们的已配置主 QQ 主人承接。
