# 常见问题

按症状查，别从头读。日志都在 `%USERPROFILE%\.dsh\plugins-data\aurabot\logs\`。

## 一定要 Windows 吗

不。AuraBot 本体在 Windows / Linux / macOS 都能跑。Windows 省事的地方在于 QQ 网关（SnowLuma）和翻唱（RVC）支持最好；Linux 接自己的 OneBot v11 就行，语音要 Python 虚拟环境。

## 会被腾讯封号吗

和所有第三方 QQ 机器人一样有风险。用的是你自己的号和你自己选的网关，所以：别拿主号、别群发、别高频打扰陌生人。

## 装完 AuraBot，左侧栏没出现

1. 重启 DSH（`dsh plugin add` 之后必须重启）
2. 确认装的是对的 profile：`dsh plugin --profile <name> list`
3. 看 DSH 自己的日志，加载失败通常有明确报错

细节见[安装 AuraBot](/guide/install-aurabot#验证装成功了没)。

## 她完全不回消息

按顺序查：

| 检查项 | 在哪看 |
| --- | --- |
| 总开关开了吗 | 「概览」页 |
| 是不是还在试运行 | 「概览」页 |
| 网关连上了吗 | 「连接」页显示在线与否 |
| 对方在白名单里吗 | 「权限」页 |
| 模型报错了吗 | 「模型」页，或 DSH「设置 → 模型」 |
| 群聊要不要回 | 「群聊」页，有的群默认只围观 |

## 「QQ 网关」一直连不上

机器人号的 QQ 开着吗？QQ 重启过的话，回「连接」页点「接入机器人号」。

「接入机器人号」说找不到：确认机器人号已登录完成，等十几秒再点一次。

## 重启 DSH 后有一阵发不出消息

一般不用管。网关暂时连不上时会自动等几秒重试；上一个 SnowLuma 还没退干净时会先等它释放端口，或者直接接着用它。刚连上那一会儿收到的消息也会补上。

日志里看到「网关暂时连不上，…后重试」是正常的；一直重试失败再看上面的条目。

## 模型报 401 / 403

密钥问题。回 DSH「设置 → 模型」重填，注意有些提供商除了密钥还要 project 或账号 ID。

## 面板打不开或一保存就 403

放反代了但没配 `security.trustedProxy` 和 `security.publicHostname`，见[认识面板](/guide/configure#放到反向代理后面)。

## DSH 启动时报 Web authentication failed

这是 DSH 自己的问题（本机登录 Cookie 攒太多）：

1. 关掉 DSH
2. 删 `%APPDATA%\@deepseek-ai\dsh-desktop\Network\Cookies` 里 127.0.0.1 的旧 Cookie
3. 重开 DSH

## 画不出图

先确认「画图」页走的是哪条路：内置三条，还是 DSH 已接入的模型。走第四条时**必须自己选一个模型**。完整排查见[画图](/features/image#出不来图怎么查)。

## 语音发不出来

会自动改发文字。想恢复语音，先在「语音」页点「安装 edge-tts」，再看试听通不通。见[语音](/features/voice)。

## 翻唱用不了

两件事：只在 Windows 上跑通；要 RVC 环境 + 一个音色。失败时不会报错，只是退回原声，原因写在日志里。见[翻唱](/features/cover)。

「读不了某个模型文件」多半是杀毒软件拦了——把翻唱目录加进信任区，还不行就删掉那个文件重新下载。

## 点歌发不出来

九成是缺 `ffmpeg`。见[点歌](/features/music#排错)。

## 桌宠明明在跑，面板显示离线

先看 DSH 桌面端的「**浏览器访问**」开关开没开。它关着时，桌宠客户端发出的所有请求（包括心跳）都会被 DSH 当成普通浏览器请求拦下，一律 403，在线状态永远登记不上——**桌宠程序本身没坏**。

把开关打开，下一次心跳（半分钟内）就自动上线。

## 某个功能的标签页不见了

去「已安装」页看对应模块是不是关了。关掉模块 = 整页消失。

## 装了自己写的模块后她不对劲

「已安装」页打开「安全模式」，你写的模块全部不加载。恢复正常就说明是那个模块，看它那一行的报错。

## 回复很慢

「模型」页把思考强度选「低」；也取决于模型服务本身的速度。

## 我的配置和记忆在哪，换电脑怎么带走

```text
%USERPROFILE%\.dsh\plugins-data\aurabot\
```

走「系统 → 备份」点「立即备份」，把文件拖到新电脑同一页，重启 DSH 自动恢复。**别手拷单个文件**，也别把备份发给别人（里面有账号凭证）。

## 模块改了没生效

自己写的模块保存即热重载（等 3 秒）；装了新版本要重启 DSH。面板「已安装」页有模拟测试，可以用它确认是不是只有发送环节没通。开发细节见[如何开发我们的框架](/dev/develop-framework)。
