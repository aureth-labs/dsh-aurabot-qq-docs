# 配置模型

DSH 自己不产模型，它只是把请求转发给你配的提供商。**没配模型，AuraBot 一句都说不出来。**

## 最快的一条路：DeepSeek 官方

1. 打开 Web UI 的 **设置 → 模型**
2. 在 DeepSeek 卡片里填 [API 密钥](https://platform.deepseek.com/)
3. **保存**，不需要重启，下一次请求就用新密钥

密钥是只写的：保存后页面只拿到脱敏预览，明文存在 `$DSH_HOME/.credentials.yaml` 里。

## 换别家：第三方提供商

点 **添加模型提供商**，卡片默认停在「第三方模型提供商」，从内置列表里选一个再填密钥。
列表里显示的是 provider id，常见几个：

| 提供商 | provider id |
| --- | --- |
| Anthropic | `anthropic` |
| OpenAI | `openai` |
| Kimi（月之暗面） | `moonshotai` |
| 智谱 GLM | `zai` |

密钥留空时，DSH 会去读该提供商声明的环境变量，绿色提示表示检测到了。

## 中转站 / 自建网关：自定义模型 API

把卡片切到「自定义模型 API」，四个字段不能填错：

| 字段 | 说明 |
| --- | --- |
| Provider ID | 小写，永久有效；改名等于新建一个提供商 |
| 基础 URL | 网关地址，Gemini 协议要带版本号，如 `https://gateway.example/v1beta` |
| API 协议 | `openai-completions` / `openai-responses` / `anthropic-messages` / `google-generative-ai` |
| 模型 | 至少一个模型 ID |

协议必须和网关实际说话的方式一致，填错的表现通常是 400 或响应解析失败。
不确定就先点 **获取可用模型** 探测一下；探测失败也不影响手填模型 ID。

## 选模型

配置好的提供商会出现在模型选择器里。**选中一个模型 = 把它设成新会话的默认值**，
已经在跑的会话保留自己日志里记录的模型。

## AuraBot 里的模型

插件装好之后，面板左侧「说话 → 模型」可以单独指定会话用哪个模型、要不要按场景换模型。
它读的是上面这套配置，所以先把 DSH 的设置配好，再来调插件。

## 排错

| 现象 | 先查什么 |
| --- | --- |
| 模型选择器里没有我要的模型 | 提供商保存了吗？模型列表是不是空的？ |
| 401 / 403 | 密钥错了、过期了，或者该提供商需要额外的 project / 账号 ID |
| 400 或响应解析失败 | 协议选错了，换个 `API 协议` 再试 |
| 中文乱码或截断 | 网关不支持流式，先在提供商设置里关掉流式 |
