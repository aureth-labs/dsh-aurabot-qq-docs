# QQ 命令与白名单

有三个东西决定「她会不会理你」：**白名单**（谁可以跟她说话）、**权限**（她能做什么）、**命令**（你在 QQ 里直接管她）。

## 白名单

面板「说话 → 权限」。

| 名单 | 管什么 | 不加会怎样 |
| --- | --- | --- |
| 群白名单 | 哪些群她能说话 | 群消息她一律不理 |
| 私聊白名单 | 哪些人可以私聊她 | 陌生人私聊她不理 |

把机器人号拉进群之后，记得**手动把群号加进群白名单**——拉进群 ≠ 她会说话。

## 权限三档

每个敏感操作单独设：

| 档位 | 含义 |
| --- | --- |
| 关 | 任何人都不能用 |
| 仅主人私聊（多数默认） | 只有你和她的私聊里能用 |
| 所有人 | 谁都能用，慎用 |

执行前会**再查一遍**，不只看提示词。试运行时只回话、不真做。

| 场景 | 默认行为 |
| --- | --- |
| 主人私聊 | 挂完整工具 |
| 群聊、别人的私聊 | **不挂任何本机工具** |
| 改资料、发文件、点歌、生图 | 要求「这一轮说话的人全是主人」 |

「主人」就是设置向导里填的那个 QQ 号。

## 命令表

主人在私聊或白名单群里发，别人发了不算；**总开关关着时也能用**。

| 命令 | 作用 |
| --- | --- |
| `/silent`（`/闭嘴`） | 这个聊天先不说话；`/silent 30` 是安静 30 分钟 |
| `/active`（`/说话`） | 解除闭嘴 |
| `/quiet` | 这个群：不插话 |
| `/chatty` | 这个群：话多一点 |
| `/normal` | 这个群：恢复默认 |
| `/model`（`/模型`） | 看能用的模型 |
| `/model 2` | 按序号换模型 |
| `/model 名字` | 按名字换 |
| `/model 默认` | 跟随 DSH 默认 |
| `/status`（`/状态`） | 看她现在的状态 |
| `/diary`（`/日记`） | 马上写一篇空间日记 |
| `/remember 内容`（`/记住`） | 让她记住一件事 |
| `/reset`（`/重开`） | 这个聊天重新开始 |
| `/off` `/on` | 关掉 / 打开总开关 |
| `/sing 歌名` | 用她的音色唱一首 |
| `/help` | 看全部命令 |

## 按聊天选模型

面板「说话 → 模型」→「按聊天选模型」：

1. 两个下拉框选「私聊默认模型」「群聊默认模型」
2. 要给某个 QQ / 某个群单独指定，展开下面的小列表加一行（再点「移除」删掉）

优先级从高到低：

```text
这个私聊（QQ 号）
  > 这个群（群号）
    > 所有私聊 / 所有群默认
      > 全局模型（「聊天用的模型」或 DSH 默认）
```

没选、或者选的模型在 DSH 里找不到，就自动落到下一级。存在 `config.json` 的 `chatModels` 里，重启不丢，**从那个聊天的下一条消息起生效**。

只有主人能改。聊天里的人说什么都换不了；扩展模块的 `model` 挂钩仍在这之后运行。

## 让她暂时安静

| 想干什么 | 用什么 |
| --- | --- |
| 全局别说话 | 右上角总开关 |
| 只在某个群安静 | `/silent` 或 `/quiet` |
| 只看她想说什么 | 打开试运行 |

`/silent` 只影响那一个聊天，是临时的；总开关是全局的，一直有效到你再打开。
