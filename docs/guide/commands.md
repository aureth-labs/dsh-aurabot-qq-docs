# QQ 命令

本页列出当前 V1 的 QQ 管理命令。V2 将通过 `ctx.command()` 注册指令，前缀由全局配置管理。

命令通常只允许主人在私聊或白名单群中使用；总开关关闭时，管理命令仍可执行。白名单和权限见[面板配置](/guide/configure#白名单与权限)。

## 命令列表

| 命令 | 作用 |
| --- | --- |
| `/silent`、`/闭嘴` | 暂停当前聊天的回复；`/silent 30` 表示 30 分钟 |
| `/active`、`/说话` | 恢复当前聊天的回复 |
| `/quiet` | 禁止当前群主动插话 |
| `/chatty` | 提高当前群的主动回复程度 |
| `/normal` | 恢复当前群的默认策略 |
| `/model`、`/模型` | 查看可用模型 |
| `/model 2` | 按序号选择模型 |
| `/model 名字` | 按名称选择模型 |
| `/model 默认` | 使用 DSH 默认模型 |
| `/status`、`/状态` | 查看运行状态 |
| `/diary`、`/日记` | 生成一篇空间日记 |
| `/remember 内容`、`/记住 内容` | 添加一条记忆 |
| `/reset`、`/重开` | 重新开始当前聊天 |
| `/off`、`/on` | 关闭或开启总开关 |
| `/sing 歌名` | 请求翻唱 |
| `/help` | 查看命令帮助 |

## 按聊天选择模型

模型选择的优先级为：

```text
当前私聊或当前群
  > 私聊默认或群聊默认
    > 全局模型
```

配置保存在 `config.json` 的 `chatModels` 中，从该聊天的下一条消息开始生效。未配置或模型不可用时，自动使用下一级配置。

## 临时停止回复

| 范围 | 方法 |
| --- | --- |
| 全部聊天 | 关闭总开关 |
| 当前聊天 | `/silent` |
| 当前群的主动插话 | `/quiet` |
| 只检查生成结果 | 开启试运行 |

`/silent` 只影响当前聊天；总开关影响全局。
