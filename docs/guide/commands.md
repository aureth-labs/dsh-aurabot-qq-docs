# 平台指令

AuraBot V2 默认不注册任何内置业务指令。回复决策、模型选择和运行管理应优先在 Web UI 或 AuraBot 面板中完成，平台消息主要交给模型与工具处理。

## 默认策略

不注册业务指令的原因不是禁止插件扩展，而是避免用户依赖固定格式的操作：

- 能够通过 Web UI 或面板完成的操作，不要求用户在平台发送命令。
- 需要理解语境或传入复杂参数的操作，优先注册为模型工具。
- 插件仍可按自身需要注册指令，但这些指令不属于 AuraBot 默认功能。

因此，新安装的 AuraBot 不会提供静音、切换模型、查看状态、重置会话等内置命令。对应的配置和管理入口以 Web UI 或面板为准。

## 可选测试指令

全局配置提供独立的测试指令开关，默认关闭。开启后只注册一条用于检查收发链路的指令：

| 指令 | 回复 | 用途 |
| --- | --- | --- |
| `/ping` | `pong` | 检查平台消息能否进入框架并成功发送 |

该开关只用于部署排查，不扩展其他命令。关闭开关后，框架不注册测试指令。

测试成功只说明平台连接和发送链路可用，不代表模型配置、人格、工具或群白名单已经配置正确。
