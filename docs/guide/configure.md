# 认识面板

装完之后所有开关都在面板里。面板分四组，先认路再调参。

::: warning 不适用于 V2 版本
这一页写的是 V1 的面板。V2 会把配置项改成 Schema 声明、由 WebUI 自动渲染，页面名和分组都会变。
等 V2 定稿后整页重写，现在只当参考。
:::

## 面板导航

| 分组 | 页面 |
| --- | --- |
| 概览 | 状态、日志、日志级别 |
| 说话 | 连接、人格、权限、群聊、模型、语音、表情包、画图、心情与记忆、人物记忆 |
| 生活 | QQ 空间、B 站、翻唱、主动搭话、桌宠、模块市场 |
| 系统 | 工作区、备份、关于、更新 |

右上角还有两个全局开关：**总开关**和**试运行**。

## 第一件事：确认「默认全关」

新装好是 **总开关关 + 试运行开**。这时候她已经会读消息、会想，但不会真的发出去。

```text
1. 「连接」页确认机器人号和网关都通
2. 「人格」页挑一张人格卡（或者自己改）
3. 「日志」页看试运行的输出，确认语气和内容你能接受
4. 再打开总开关
```

## 日常怎么用

| 想做的事 | 去哪里 |
| --- | --- |
| 让她暂时别说话 | 关掉右上角的总开关 |
| 只看她想说什么、不真发 | 打开试运行 |
| 把她拉进一个群 | QQ 里拉进群，再去「权限」页把群号加进群白名单 |
| 允许某个朋友私聊她 | 「权限」→ 私聊白名单，加上对方 QQ 号 |
| 改她的性格 | 「人格」页直接改文字，保存后下一句起生效 |
| 换一套人格 | 「人格」页选中一张，点「设为当前」 |
| 让她在群里话多 / 话少 | 「群聊」页调插话概率，也可以只对某个群单独设 |
| 在私聊里让她操作电脑 | 「权限」→「主人私聊的权限」选「完整」（默认就是） |
| 换声音 | 「语音」页选音色点「生成」试听 |
| 管理表情包 | 「表情包」页改名字、删除、上传 |
| 让她马上写一篇空间日记 | 「QQ 空间」→「现在写一篇」 |
| 让她现在来找你 | 「概览」或「主动搭话」→「现在就让她来找我」 |
| 看她和某个人聊了什么 | 左侧栏「Aurabot · QQ」工作区，点对应会话 |
| 插一句话帮她回 | 在那个会话里直接打字，她这一轮的回复也会发到 QQ |

## 在 QQ 里直接管她

`/silent` `/active` `/status` `/model` `/diary` `/remember` `/sing` 这些命令，总开关关着也能用。完整表见 [QQ 命令与白名单](/guide/commands)。

## 白名单与权限

白名单是最容易漏的一步：**拉进群 ≠ 她会说话**，群号要显式加进去。

| 名单 | 管什么 | 不加会怎样 |
| --- | --- | --- |
| 群白名单 | 哪些群她能说话 | 群消息她一律不理 |
| 私聊白名单 | 哪些人可以私聊她 | 陌生人私聊她不理 |

「权限」页给每个敏感操作单独设三档：**关 / 仅主人私聊 / 所有人**。执行前会再查一次。

| 场景 | 默认行为 |
| --- | --- |
| 主人私聊 | 挂完整工具 |
| 群聊、别人的私聊 | **不挂任何本机工具** |
| 改资料、发文件、点歌、生图 | 要求「这一轮说话的人全是主人」 |

「主人」就是向导里填的那个 QQ 号。想让别人也能触发敏感操作，得在这里显式放开。

## 数据在哪

```text
%USERPROFILE%\.dsh\plugins-data\aurabot\
├─ config.json     设置
├─ personas\       人格
├─ modules\        你自己写的模块（升级不覆盖）
├─ local\          本地接口脚本（语音 / 生图 / 翻唱 / 识别）
├─ logs\           日志
└─ ...             记忆、表情、日记
```

换电脑走「系统 → 备份」点「立即备份」，把生成的文件拖到新电脑同一页（首次向导里也有入口），重启 DSH 后会自动换上设置和数据、重新下载市场模块、放回 QQ 会话。

::: warning 备份里有账号凭证
别把备份发给别人。另外 DSH 自己的设置、QQ 网关登录、抖音 / 小黑盒的浏览器登录**不在备份里**，要重新弄。
:::

## 放到反向代理后面

面板默认只接受本机回环访问，并且带跨站防护。要远程访问，除了在「安全防护」页打开 `security.panelRemoteAccess`，还必须配两个字段，否则等于把管理接口裸奔出去：

| 字段 | 填什么 | 不填的后果 |
| --- | --- | --- |
| `security.trustedProxy` | 反代地址 | 插件按 TCP 对端判断来源，反代部署下对端永远是反代自己，所有请求都被当成本机 |
| `security.publicHostname` | 面板对外域名 | 跨站防护不认这个域名，远端一保存就 403 |

反代只放行面板真正需要的精确路径，**不要整段 `/aurabot/api/*` 放过去** ——
那会把没有独立鉴权的模块接口一起暴露。

另外反代要在应用层再加一道认证（Basic Auth / OAuth），别把 `panelRemoteAccess` 当成唯一防线。

## 装社区模块

面板「模块市场」一键装 / 更新 / 卸载，仓库在 [dsh-aurabot-qq-mods](https://github.com/aureth-labs/dsh-aurabot-qq-mods)。

自己写的模块放数据目录的 `modules/` 下，升级不覆盖，保存即生效。见[装社区模块](/guide/install-plugin)。

::: warning 模块不是沙箱
模块和插件在同一个进程里跑，能碰到账号配置。安装时显示的能力只是**声明**。只装信得过的模块。
:::
