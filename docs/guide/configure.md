# 配置 AuraBot

装完之后所有开关都在面板里。面板分成四组，先认路再调参。

## 面板导航

| 分组 | 页面 |
| --- | --- |
| 概览 | 状态、日志、日志级别 |
| 说话 | 连接、人格、权限、群聊、模型、语音、表情包、画图、心情与记忆、人物记忆 |
| 生活 | QQ 空间、B 站、翻唱、主动搭话、桌宠、模块市场 |
| 系统 | 工作区、备份、关于、更新 |

## 第一件事：确认「默认全关」

新装好是 **总开关关 + 试运行开**。这时候她已经会读消息、会想，但不会真的发出去。

流程建议：

1. 在「连接」里确认机器人号和网关都通
2. 在「人格」里挑一张人格卡（或者自己改）
3. 看「日志」里试运行的输出，确认语气和内容你能接受
4. 再打开总开关

## 权限怎么理解

「权限」页给每个敏感操作单独设三档：**关 / 仅主人私聊 / 所有人**。执行前会再查一次。

| 场景 | 默认行为 |
| --- | --- |
| 主人私聊 | 挂完整工具 |
| 群聊、别人的私聊 | 不挂任何本机工具 |
| 改资料、发文件、点歌、生图 | 要求「这一轮说话的人全是主人」 |

「主人」就是设置向导里填的那个 QQ 号。想让别人也能触发敏感操作，得在这里显式放开。

## 数据在哪

```
%USERPROFILE%\.dsh\plugins-data\aurabot\
```

配置、人格、表情、日记、记忆、日志、你自己写的模块都在这儿。
换电脑走「系统 → 备份」打成 zip 带走，别手动拷。

## 放到反向代理后面

面板默认只接受本机回环访问，并且带跨站防护。要远程访问，除了在「安全防护」页打开
`security.panelRemoteAccess`，还必须配两个字段，否则等于把管理接口裸奔出去：

| 字段 | 填什么 | 不填的后果 |
| --- | --- | --- |
| `security.trustedProxy` | 反代地址 | 插件按 TCP 对端判断来源，反代部署下对端永远是反代自己，所有请求都被当成本机 |
| `security.publicHostname` | 面板对外域名 | 跨站防护不认这个域名，远端一保存就 403 |

反代只放行面板真正需要的精确路径，不要整段 `/aurabot/api/*` 放过去 ——
那会把没有独立鉴权的模块接口一起暴露。

## 装社区模块

面板「模块市场」一键装/更新/卸载，仓库在
[dsh-aurabot-qq-mods](https://github.com/aureth-labs/dsh-aurabot-qq-mods)。

自己写的模块放数据目录的 `modules/` 下，升级不覆盖，保存即生效。

::: warning 模块不是沙箱
模块和插件在同一个进程里跑，能碰到账号配置。安装时显示的能力只是**声明**。
只装信得过的模块。
:::
