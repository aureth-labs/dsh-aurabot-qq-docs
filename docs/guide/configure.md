# 面板配置

## 主人与群聊唤醒词

在平台接入配置中填写该平台的主人 ID。授权使用平台原始 ID，例如 Telegram 私聊用户的数字 ID。权限页的全局设置可以编辑群聊唤醒词，每行一个。清空列表后仍可以直接提及机器人。

## 用户与频道权限

打开「权限 → 平台权限」。收到消息后，用户和频道会出现在对应列表中。可以搜索 ID、名称或备注，也可以提前添加尚未发过消息的 ID。权限修改保存后从下一条消息开始生效。

| 对象 | 等级与作用 |
| --- | --- |
| 用户 | 默认 1。0 表示封禁。2 至 5 可访问要求对应等级的频道或插件指令。 |
| 接入配置中的主人 | 对应平台及实例内为 5。主人身份在接入设置中维护。 |
| 频道 | 默认接收 1 级及以上用户的消息。提高等级可以限制参与者，填 0 关闭该频道。 |

填写机器人实例时，规则只作用于这个实例。封禁同平台的所有实例可选择「用户」，填写平台和用户 ID，将机器人实例留空，等级设为 0。跨实例封禁优先于该用户在单个实例上的普通授权。不同平台可以有相同的用户和频道 ID。

「备注」由管理员维护，平台下次更新昵称时会保留。移除记录会清除该记录的备注和授权，下一次收到消息后重新登记。用户等级不改变框架的主人身份，也不授予 DSH 面板管理权。

升级前如果设置过 QQ 群专属头衔过滤，请核对需要屏蔽的成员，在平台权限页登记他们的用户 ID。头衔会改变，也可能有多人共用，V2 按成员 ID 匹配。原有按指定 QQ 群成员设置的规则仍在群聊设置中。
