# 面板配置

本页说明当前 V1 面板的配置结构。V2 将使用 Schema 生成配置界面，页面名称和分组可能变化。

## 配置分组

| 分组 | 主要内容 |
| --- | --- |
| 概览 | 运行状态、日志和日志级别 |
| 说话 | 连接、人格、权限、群聊、模型和多媒体功能 |
| 生活 | QQ 空间、B 站、翻唱、主动搭话、桌宠和模块市场 |
| 系统 | 工作区、备份、版本和更新 |

总开关控制实际回复；试运行保留处理过程，但不向平台发送结果。

## 首次检查

1. 确认平台连接正常。
2. 选择人格并检查模型配置。
3. 在试运行状态下发送测试消息。
4. 检查日志中的回复和权限判断。
5. 确认结果后开启总开关。

## 常用配置

| 需求 | 配置位置 |
| --- | --- |
| 暂停全部回复 | 总开关 |
| 只查看生成结果 | 试运行 |
| 允许群聊回复 | 「权限」中的群白名单 |
| 允许指定用户私聊 | 「权限」中的私聊白名单 |
| 修改人格 | 「人格」 |
| 调整群聊插话 | 「群聊」 |
| 更换声音 | 「语音」 |
| 管理表情包 | 「表情包」 |
| 查看会话 | AuraBot 工作区中的对应会话 |

## 白名单与权限

白名单决定机器人处理哪些聊天，权限决定允许执行哪些操作。二者分别配置。

| 名单 | 作用 |
| --- | --- |
| 群白名单 | 允许响应的群聊 |
| 私聊白名单 | 允许响应的私聊用户 |

敏感操作可设为「关」「仅主人私聊」或「所有人」。当前 V1 默认不在群聊和他人私聊中提供本机工具；修改资料、发送文件、点歌和生图等操作还会检查本轮发言者身份。

「主人」是 V1 配置中的管理账号概念。权限在执行阶段再次检查，不只依赖提示词。

## 数据与备份

Windows 默认数据目录：

```text
%USERPROFILE%\.dsh\plugins-data\aurabot\
├─ config.json
├─ personas\
├─ modules\
├─ local\
├─ logs\
└─ 其他记忆、表情和日记数据
```

迁移时使用「系统 → 备份」生成完整备份，不要只复制其中几个文件。备份可能包含账号凭据，不应公开分享。

DSH 自身配置、QQ 网关登录状态以及外部网站的浏览器登录状态不一定包含在备份中，恢复后需要分别检查。

## 反向代理

远程开放面板时，除启用 `security.panelRemoteAccess` 外，还需要正确配置：

| 字段 | 用途 |
| --- | --- |
| `security.trustedProxy` | 指定可信反向代理，避免来源判断失效 |
| `security.publicHostname` | 指定面板对外主机名，通过跨站请求校验 |

只代理面板需要的路径，不要直接开放整个 `/aurabot/api/*`。反向代理还应提供独立的访问认证。

## 模块安全

能力声明用于说明模块可能访问的资源，不构成沙箱。模块与 AuraBot 在同一进程中运行，只安装来源明确、代码可审查的模块。
