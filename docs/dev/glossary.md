# 术语表

本表规定本站正文中的名称。引用代码、配置字段或旧版界面时保留原文，并在需要时注明所属版本。

## 核心概念

| 规范用语 | 含义 | 不要写成 |
| --- | --- | --- |
| DeepSeek Harness（DSH） | 提供会话、模型、工作区、Web UI 和插件加载能力的宿主程序 | DeepSeekharness、DeepSeekHarness、DPSK Harness、深度求索工具箱 |
| AuraBot | 运行在 DSH 中的机器人框架 | Aura BOT、Aurabot（代码标识符和现有界面标签除外）、QQ 插件 |
| 框架 | AuraBot 整体及其公共能力 | 主程序、宿主程序、本体 |
| 主仓库 | 保存 AuraBot 框架源码的仓库；开发语境中也称主框架仓库 | 市场仓库、文档仓库 |
| 宿主 | 加载 AuraBot 的 DSH | AuraBot 本身 |
| 插件 | 安装到 DSH 或 AuraBot 中、扩展其能力的代码包；泛指扩展时使用 | 扩展、应用、脚本 |
| DSH 插件 | 由 DSH 加载的插件 | AuraBot 模块 |
| AuraBot 插件 | 由 AuraBot 加载的插件；V2 文档中的默认插件形态 | DSH 本体、平台适配器的统称 |
| 模块 | V1 中由 AuraBot 加载的功能包；仅在讨论 V1 接口、市场或兼容层时使用 | 所有插件的泛称 |
| 内置模块 | 随 AuraBot V1 提供的模块 | 自带插件、原生插件 |
| 社区模块 | 由社区作者发布、通过市场安装的 V1 模块 | 官方插件、第三方扩展 |
| 适配器 | 负责平台连接、消息转换和投递的组件 | 网关、机器人插件、平台工具 |
| 适配器插件 | 以插件形式提供的适配器 | `ctx.adapter`（未采用的设计） |
| 机器人实例 | 已配置账号并由适配器管理的 Bot 对象 | 机器人进程、机器人客户端 |
| 会话 | 模型交互所使用的对话上下文 | 聊天记录、聊天窗口 |
| 消息 | 平台传入或框架发出的内容 | 对话、请求 |
| 消息管线 | 消息经过指令、中间件和模型阶段的处理过程 | 消息管道线、回调链 |
| 工具 | 注册给模型调用的能力 | 指令、函数调用插件 |
| 指令 | 用户按规定格式直接触发的命令 | AI 工具、斜杠工具 |
| 中间件 | 在消息管线中检查、修改或消费消息的处理函数 | 拦截器、消息钩子 |

## 平台与连接

| 规范用语 | 含义 | 不要写成 |
| --- | --- | --- |
| 平台 | QQ、Telegram、Discord 等消息服务 | 渠道、应用市场 |
| QQ 网关 | 实现 OneBot v11、帮助 QQ 账号收发消息的软件 | 适配器、模型网关 |
| OneBot v11 | QQ 机器人常用的消息协议 | OneBot11、onebot v11 |
| SnowLuma | QQ 网关的一种实现 | Snow Luma、snowluma（代码和文件名除外） |
| NapCat | QQ 网关的一种实现 | Napcat、NAPCAT |
| LLOneBot | QQ 网关的一种实现 | LLonebot、LLOne Bot |
| Lagrange | QQ 网关的一种实现 | lagrange（代码和包名除外） |
| 模型网关 | 统一转发模型请求并处理路由、重试等逻辑的服务 | QQ 网关、机器人网关 |
| Magpie | 独立模型网关项目 | Mapie、Magic Pie、AuraBot 网关 |
| 模型提供商 | 提供模型 API 的服务方 | 模型厂商、模型插件 |

「QQ 网关」和「模型网关」属于不同层次。前者处理平台消息，后者处理模型请求，正文中不得简写成同一个「网关」。

## 消息与模型

| 规范用语 | 含义 | 不要写成 |
| --- | --- | --- |
| 模型 | 被调用的具体大语言模型或多模态模型 | AI 大脑、引擎（泛指时） |
| 模型 ID | 提供商用于识别模型的字符串 | 模型名称（展示名称另说） |
| 默认模型 | 新会话使用的模型 | 全局唯一模型、旧会话模型 |
| 上下文 | 本轮模型调用可读取的消息、系统提示和相关资料 | 记忆库、聊天记录全文 |
| 记忆 | 持久保存并按需检索的信息 | 上下文、数据库全文 |
| 人格卡 | 可保存和切换的人格配置 | 人格模块 |
| 语音合成（TTS） | 将文字转换为语音 | 翻唱、变声 |
| 语音识别（ASR） | 将语音转换为文字 | 语音合成、语音理解 |
| 翻唱 | 使用音色转换等流程生成演唱音频 | TTS、语音条 |
| 元素树 | 结构化消息内容 | XML 字符串、消息块数组（二者不完全等同） |
| Satori | 消息与平台交互协议及其元素定义的参考基线 | 适配器框架、Koishi 本体 |

## 文件与目录

| 路径或名称 | 固定含义 |
| --- | --- |
| `src/` | TypeScript 等源码目录 |
| `lib/` | 后台代码的 JavaScript 构建产物目录，不是 `src/` 的子目录 |
| `client/` | V1 自定义面板源码目录 |
| `dist/` | 面板等前端代码的构建产物目录 |
| `index.mjs` | V1 本地模块的入口文件之一；是否进入发布包取决于加载约定 |
| `lib/index.js` | 常见的后台编译入口，最终由 `package.json` 的 `main` 指定 |
| `market.json` | 宿主读取的市场索引 |
| `registry.jsonl` | 市场仓库维护的收录清单 |
